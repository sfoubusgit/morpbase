# MorpBase V2 Illustrator-Oriented Asset Map Prompt

## Purpose

Create the first practical asset map for the MorpBase V2 design universe.

This map should answer:

- what deserves true custom asset design
- where each asset family belongs
- what priority each asset family has
- what should stay code-led for now
- and what should wait until later

## Important Constraint

Do not turn this into:

- broad brand exploration
- a moodboard
- or generic "design ideas"

This is an execution map.

The product truths are already frozen.
The goal is to identify the custom asset layer that will best strengthen:

- shell identity
- signature-surface inevitability
- threshold moments
- and restrained symbolic support

## Required Method

Start from product use, not from decorative categories.

### Pass 1. Shell use

Ask:

- what custom marks or joins would most improve the shell immediately?

### Pass 2. Threshold use

Ask:

- which product crossings deserve true custom threshold language?

### Pass 3. Trace use

Ask:

- where do traces and carried marks help the product feel more native?

### Pass 4. Realm use

Ask:

- which realm-specific accents are actually needed, and which would be too much?

### Pass 5. Signature-surface use

Ask:

- which of the six signature surfaces most need custom framing support?

## Required Output

Produce:

1. asset-map purpose
2. asset families
3. priority tiers
4. product locations for each family
5. what each family should communicate
6. what can remain CSS/code-led for now
7. what should wait until later
8. practical order for asset creation

## Decision Standard

The best asset map will:

- strengthen inevitability
- stay restrained
- support the one-engine reading
- and avoid decorative drift

## Tone

Keep the result practical, selective, and plain.
