# MorpBase V2 Whole-Product Inevitability Brief

## Phase Purpose

Make the current coded V2 feel:

- more settled
- more singular
- more authored
- more unmistakably like MorpBase

without adding new systems.

## Main Design Targets

### 1. Shell inevitability

The shell should feel like:

- a real authored frame
- not just a correct navigation structure

### 2. Realm family coherence

`Workspace`, `Memory`, `Community`, and `Continuity` should feel:

- clearly different
- but clearly of one world

### 3. Signature focus surfaces

The product’s key focus areas should feel:

- more signature-rich
- more inevitable
- more obviously central to the product’s identity

### 4. Symbolic foundation

The subtle symbolic layer should be:

- clearer
- more intentional
- ready for later Illustrator-built reinforcement

## What This Phase Should Not Become

- no new features
- no final decorative art pass
- no generic polish exercise
- no separate visual universe detached from the product’s logic

## Success Condition

This phase succeeds if the next time we inspect coded V2, the honest reaction becomes:

- `this feels like MorpBase`

more than:

- `this is a strong prototype of MorpBase`
