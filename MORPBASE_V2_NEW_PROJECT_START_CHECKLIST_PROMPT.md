# MorpBase V2 New Project Start Checklist Prompt

Use this prompt after the new V2 project build brief is complete.

Your job is to turn the build brief into a practical startup checklist for the actual beginning of the new MorpBase V2 project.

## Core Goal

Create a short checklist that makes the new project start disciplined and clear.

It should answer:

- what has to be set up first
- what the active control docs are
- what the first implementation focus is
- what should explicitly stay out
- and what first checkpoint the build should aim toward

## Required Inputs

Read these first:

- `MORPBASE_V2_NEW_PROJECT_BUILD_BRIEF.md`
- `MORPBASE_V2_SLICE_1_IMPLEMENTATION_PACK.md`

## Main Questions

Answer these directly:

1. What should happen before any coding starts?
2. What should be kept visible while coding begins?
3. What is the first implementation focus?
4. What should the team explicitly avoid at project start?
5. What is the first checkpoint target?

## Required Output

Write one concise startup checklist that includes:

- purpose
- setup checklist
- active control docs
- first implementation focus
- explicit non-goals
- first checkpoint target

Save the result as:

- `MORPBASE_V2_NEW_PROJECT_START_CHECKLIST.md`

## Important Rules

- Keep it practical and compact.
- Do not turn it into a general planning essay.
- Make it usable as a real project-start checklist.
