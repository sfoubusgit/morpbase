# Secondary Pool: Mourning Relics and Funerary Icons

## Purpose

This document defines `Mourning Relics and Funerary Icons` as a gothic-compatible secondary pool for portrait-family hosts.

It is meant to be:

- reusable across dark portrait-family hosts
- especially strong with `Gothic Character Portrait`
- clearly secondary, not a competing identity anchor

## Core Role

This pool adds a symbolic relic and funerary-object layer.

Its purpose is to introduce variation around:

- what emblem, icon, key, relic, or devotional object is present
- what object the portrait is organized around
- what kind of funerary or death-chapel symbolism sharpens the reading

It should make portraits feel more specific and more ceremonially charged without replacing the host identity.

## What It Should Do

A strong use of this pool should create differences like:

- a portrait centered around a black rosary
- a portrait centered around a silver mourning locket
- a portrait centered around a coffin key or reliquary pendant
- a portrait centered around a votive lantern or saint-medallion icon

These changes should produce meaningful variation while preserving:

- host style
- host composition family
- host lighting family
- host overall portrait identity

## What It Should Not Do

This pool should not try to define:

- the whole gothic family
- the main emotional baseline
- the full attire system
- the core portrait identity

If it starts doing those things, it stops being secondary.

## Host Compatibility

### Best-fit hosts

- gothic portrait hosts
- dark ritual portrait hosts
- cathedral / saintly portrait hosts
- baroque mourning portrait hosts
- witch / occult portrait hosts with funerary symbolism

### Especially good with

- `Gothic Character Portrait`

### Partial-fit hosts

- aristocratic dark portrait hosts
- dark editorial portrait hosts
- industrial-goth portrait hosts when the relic objects lean iron, chain, and hardware-adjacent

## Structural Shape

This pool should stay narrower than a main pool.

Recommended sections:

- `Props`
- `Effects`
- `Mood`

That is enough.

## Section Purpose

### Props

This is the core section.
It defines the actual relic, icon, or funerary object being introduced.

### Effects

This section supports the relic’s aura and presentation.

### Mood

This section supports the symbolic reading without replacing the host pool’s full emotional identity.

## Initiative Phrase Rule

This pool should have:

- no IDPs
- no initiative phrases in v1

Why:

- the host main pool should keep identity ownership
- this pool should stay additive
- the relic layer should not become a competing baseline

## Interaction With Gothic Character Portrait

This pool is especially strong with `Gothic Character Portrait` because the main host already supports:

- portrait-centered composition
- dark attire
- symbolic motifs
- candlelight, cathedral, baroque, and funeral-goth readings

This secondary pool can then vary:

- what relic or icon becomes the focal symbol
- what devotional or funerary center the portrait revolves around

That creates meaningful iteration without replacing the host family.

## Good Candidate Test

This pool succeeds if:

1. portraits gain clear relic-centered variation
2. the host identity still dominates
3. the same secondary pool works across multiple dark portrait-family hosts
4. it does not require IDPs to be useful
5. users feel increased variation without increased chaos

## Recommended Initial Fill Level

For a first real build:

- `Props`: 10 items
- `Effects`: 10 items
- `Mood`: 10 items

That is enough to make the pool real without inflating it.

## Final Summary

`Mourning Relics and Funerary Icons` is a strong gothic-family secondary pool because it:

- creates clear symbolic-object variation
- stays clearly secondary
- works especially well with `Gothic Character Portrait`
- should also transfer to nearby dark ritual and cathedral portrait hosts

It is a disciplined next step for testing secondary-pool composition after the gothic elasticity test.
