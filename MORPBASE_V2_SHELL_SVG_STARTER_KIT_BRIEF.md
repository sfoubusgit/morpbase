# MorpBase V2 Shell SVG Starter Kit Brief

## Intent

This kit should turn the shell handoff into something you can actually open in Illustrator and start refining.

## Scope

Include only:

- top-frame join pair
- brand support fragment
- engine-join pair
- shell knot
- primary realm separator

Do not include yet:

- threshold assets
- trace assets
- larger decorative panels
- realm-specific art

## Desired Feeling

The kit should feel:

- structural
- precise
- lightly luminous
- authored

but not:

- logo-heavy
- ornamental
- or final-polish-fake

## Honest Standard

If this works, the shell family should stop being only described and start being materially executable.
