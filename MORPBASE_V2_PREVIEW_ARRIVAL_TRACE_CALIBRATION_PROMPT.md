# MorpBase V2 Preview / Arrival-Trace Calibration Prompt

## Goal

Calibrate the center after the trace family now exists across:

- `Memory`
- `Community`
- `Continuity`

The purpose of this pass is:

- to let `Workspace` read carried return more clearly
- to let `Prompt Preview` read incoming value more clearly
- and to keep the center tied to the same symbolic language without making it busier

## Main Questions

### 1. What Should Be Strengthened

- How should the center say that a line arrived carrying readable value?
- Where should that be felt most clearly?

### 2. What Must Stay Protected

- What would make the center too symbolic or too explained?
- What must still stay quiet?

### 3. Best Execution Shape

- What is the smallest effective bridge?
- Which surfaces should be touched?

## Output Format

Write the result as:

1. `Strengthen`
2. `Protect`
3. `Execution Shape`
4. `Honest Conclusion`
