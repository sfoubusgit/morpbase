# MorpBase V2 Workspace + Prompt Preview Signature Deepening Brief

## 1. The Real Center Gap

The center is now structurally strong.

The gap is:

- it still reads a little more like a very strong product prototype
- than like the inevitable heart of MorpBase

Plainly:

- `Workspace` works well
- `Prompt Preview` works well
- but their deeper signature language can still become more singular

So this pass should not ask:

- what else should the center do?

It should ask:

- how should the center feel more unmistakably like MorpBase?

## 2. Workspace Deepening Priority

`Workspace` should feel more like:

- the living instrument

That means strengthening:

- guided movement
- phase gravity
- the sense of a line taking shape
- the feeling that the user is inside a real making surface, not a product form

The strongest move here is:

- stronger authored center framing
- clearer phase-carry feeling
- stronger internal movement cues

## 3. Prompt Preview Deepening Priority

`Prompt Preview` should feel more like:

- the proof surface

That means strengthening:

- trust
- proof
- visible carry from the draft into the preview
- the sense that this is where the line starts to justify `Keep`

The strongest move here is:

- make the preview read more clearly as an emerging proof of value
- not just a text output panel

## 4. What Should Change In This Pass

### 1. Workspace frame

Strengthen:

- instrument-like reading
- active-center pressure
- calmer but clearer movement through phases

### 2. Workspace internal cues

Strengthen:

- signs that the current line is being shaped, not merely filled in

### 3. Preview proof layer

Strengthen:

- current focus reading
- visible carry of draft choices
- trust threshold feeling

### 4. Center relationship

Strengthen:

- the felt relationship between authoring and proof

So the user feels:

- shape here
- trust there

instead of:

- form here
- output there

## 5. What Should Stay Out

Do not add:

- new workflow blocks
- more input density
- more analytics or metrics
- image-tool styling
- decorative symbolic overlays across the whole center

This pass should stay:

- centered
- authored
- restrained

## 6. Success Condition

This pass succeeds if the honest reaction becomes:

- `Workspace feels more like the active MorpBase instrument`
- `Prompt Preview feels more like proof`
- `the center feels less app-like`

## 7. Honest Conclusion

The next inevitability step should deepen the center itself.

The strongest route is:

- make `Workspace` feel more like the living instrument
- make `Prompt Preview` feel more like the trust surface
- do it without adding any new product behavior
