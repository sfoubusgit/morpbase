# Secondary Pool: Sacred Emblems and Handheld Relics

## Purpose

This document defines `Sacred Emblems and Handheld Relics` as the first concrete secondary-pool candidate for portrait-family hosts.

It is meant to be:

- reusable across multiple portrait-family main pools
- especially strong with `Celestial Pixel Portrait`
- clearly secondary, not a competing identity anchor

## Core Role

This pool adds a symbolic focal-object layer.

Its purpose is to introduce variation around:

- what the character holds
- what emblem, sigil, relic, or charm is being presented
- what symbolic center the portrait is organized around

It should make portraits feel more specific and more narratively distinct without changing the underlying image family.

## What It Should Do

A strong use of this pool should create differences like:

- a portrait centered around a glowing butterfly emblem
- a portrait centered around a crystal prayer relic
- a portrait centered around a moon sigil or sacred charm
- a portrait centered around a floating shrine token or radiant seal

These changes should produce meaningful variation while preserving:

- host style
- host composition family
- host lighting family
- host overall medium identity

## What It Should Not Do

This pool should not try to define:

- the whole portrait style
- the core decorative family
- the main emotional identity
- the whole composition system

If it starts doing those things, it stops being secondary.

## Host Compatibility

### Best-fit hosts

- celestial portrait pools
- shrine portrait pools
- ritual portrait pools
- magical portrait pools
- oracle / seer portrait pools
- icon-like portrait pools

### Especially good with

- `Celestial Pixel Portrait`

### Weak-fit hosts

- hard sci-fi portrait pools with no symbolic object logic
- realistic low-ornament portrait pools
- environment-first world pools
- object showcase pools

## Structural Shape

This pool should stay narrower than a main pool.

Recommended sections:

- `Props`
- `Effects`
- `Mood`

Optional later:

- `Lighting`

That is enough.
It does not need full subject/style/composition coverage.

## Section Purpose

### Props

This is the core section.
It defines the actual sacred or symbolic object being introduced.

Example item types:

- radiant butterfly emblem
- moonlit relic shard
- crystal prayer seal
- floating sacred sigil
- jeweled charm pendant
- luminous shrine token
- star-lotus core
- relic lantern heart
- ceremonial talisman plate
- pearl-framed blessing emblem

### Effects

This section supports the object’s aura and presentation.

Example item types:

- soft sacred glow dust
- crystalline emblem sparkles
- radiant seal particles
- floating prayer motes
- tiny relic light fragments
- halo-like shimmer around the object
- magic dust trailing from the emblem
- ceremonial light haze
- gentle starburst around the relic
- luminous sigil bloom

### Mood

This section supports the symbolic reading without trying to replace the host’s main emotional identity.

Example item types:

- quiet reverence
- devotional calm
- ceremonial focus
- radiant blessing
- sacred wonder
- ritual stillness
- enchanted offering
- luminous faith
- symbolic tenderness
- solemn grace

### Optional Lighting

Only add this if needed later.
This would exist to reinforce the object presentation.

Example item types:

- object-centered glow
- soft halo light from the emblem
- underlight from a held relic
- sacred core illumination

## Initiative Phrase Rule

This pool should generally **not** have IDPs.

That is intentional.
It is a secondary pool.

Initiative phrases should also be avoided at first unless a clear workflow need appears.

Why:

- the host main pool should keep identity ownership
- this pool should stay additive
- the symbolic-object layer should not become a competing baseline

## Interaction With Celestial Pixel Portrait

This pool is especially strong with `Celestial Pixel Portrait` because the main host already supports:

- centered portrait logic
- hand-focus composition language
- luminous ornamental rendering
- celestial / sacred / occult symbolic reading

This secondary pool can then vary:

- what object or emblem is being presented
- what spiritual or magical center the portrait revolves around

That creates meaningful iteration without changing the whole image family.

## Good Candidate Test

This pool succeeds if:

1. portraits gain clear symbolic focal variation
2. the host identity still dominates
3. the same secondary pool works across multiple portrait-family hosts
4. it does not require IDPs to be useful
5. users feel increased variation without increased chaos

## Recommended Initial Fill Level

For a first real build, I would recommend:

- `Props`: 10 items
- `Effects`: 10 items
- `Mood`: 10 items

That is enough to make the pool real without inflating it.

## Final Summary

`Sacred Emblems and Handheld Relics` should be the first real portrait-family secondary pool because it:

- creates strong visible variation
- stays clearly secondary
- works especially well with `Celestial Pixel Portrait`
- should also transfer well to nearby magical / sacred / ritual portrait hosts

It is one of the cleanest ways to test secondary-pool composition in MorpBase.
