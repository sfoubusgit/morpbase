# MorpBase V2 Coded Design Translation Analysis

## Purpose

The current coded V2 no longer needs more product discovery first.

It needs a stronger translation of MorpBase's design universe into the actual new codebase.

In plain terms:

- the product now works
- but it still does not yet feel distinct enough

So this phase should strengthen expression, not reopen structure.

## What This Phase Should Strengthen

### 1. Shell identity

The top-level shell should feel less like a well-made app frame and more like a MorpBase instrument.

That means:

- stronger brand mark behavior
- stronger shell material feeling
- clearer asymmetry in the top level

### 2. Realm atmosphere inside one family

Each realm should feel more clearly itself while still belonging to the same product family:

- `Workspace` = active crafted instrument
- `Memory` = calmer archival return layer
- `Community` = outward-facing circulation energy
- `Continuity` = quieter symbolic depth

### 3. Object-carrying surfaces

The product should feel more strongly like the same meaningful work is being carried across realms.

That means:

- focus surfaces
- preview/proof surfaces
- path cues
- card families

should all feel more intentionally related.

### 4. Shape language

V2 needs a more distinct early shape language so it stops reading like generic rounded panels with gradients.

The shape language should feel:

- crafted
- slightly ceremonial
- calm
- durable

without becoming decorative theater.

## Recommended First Translation Areas

### 1. Brand mark and shell treatment

This is the fastest way to make the product feel more authored.

### 2. Realm signature accents

Each realm should get a slightly stronger identity cue without becoming a separate visual world.

### 3. Focus/proof surfaces

These are some of the most important emotional surfaces in the product.
They should feel more signature and more trustworthy.

### 4. Card and panel family behavior

Cards and panels should feel more like a designed family, not just consistent containers.

## What Must Stay Out

- no new system growth
- no fake polish detached from product meaning
- no heavy Illustrator-style asset simulation in code
- no over-decoration that weakens clarity
- no flattening of realm hierarchy

## Best First Coded Pass

The best first coded design-translation pass should focus on:

1. shell identity strengthening
2. realm-specific atmospheric accents
3. focus/proof surface strengthening
4. more distinctive panel/card shape behavior

That is enough to make the current V2 feel more like MorpBase without pretending the final art direction is already complete.

## Success Criteria

This phase succeeds if the coded V2 feels:

- more authored
- more crafted
- more archival-modern
- more distinct from generic AI/product UI

while still staying:

- clear
- disciplined
- asymmetrical
- product-real
