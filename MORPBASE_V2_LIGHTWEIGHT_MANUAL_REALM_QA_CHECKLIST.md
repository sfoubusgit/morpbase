# MorpBase V2 Lightweight Manual Realm QA Checklist

Use this as the smallest repeating support-realm inspection pass.

## Memory
- Does the entry feel like returning to living work, not opening a storage area?
- Does the main kept-work focus feel like a true return point?
- Do `Saved Work` and `Reusable Assets` still feel clearly different?
- Does the path back to `Workspace` still feel central?

## Community
- Does `Discover` still feel object-led instead of feed-led?
- Does the public result focus still feel like real work in public life?
- Do lineage, versions, and invitations still feel meaningful instead of metric-like?
- Does public work still point inward toward real creation?

## Continuity
- Does the realm still feel lighter than the others?
- Does recurrence feel readable through real work instead of explanation?
- Does `Activate` still feel like the payoff?
- Does the realm stay meaningful without becoming heavy?

## Balance
- Do the support realms still feel calmer than `Workspace`?
- Do they still feel integrated into one engine?
- Is any realm starting to pull too much equal weight against the center?

## Action Rule
- If no realm feels clearly wrong, freeze the current support-realm reading.
- Only open a tuning pass if one realm feels directly off in a user-facing way.
