# MorpBase V2 Symbolic / Motif Foundation Prompt

You are defining the **symbolic / motif foundation** for MorpBase V2 inside the broader `whole-product inevitability` phase.

This is **not** a freeform branding exercise.
It is a product-grounded design decision.

Your job is to determine:

- whether MorpBase V2 should use a symbolic layer at all
- what symbolic logic is actually native to MorpBase
- which motifs belong to the product
- how subtle or visible they should be
- where they should appear
- what must be avoided so the product does not become decorative theater

---

## Product Truth You Must Respect

MorpBase V2 is:

- one workflow-centered creative engine
- with `Workspace` as the center
- `Memory` as the second home
- `Community` as public circulation
- `Continuity` as a lighter recurrence-aware realm

It should feel like:

- a crafted creative instrument
- with archival memory
- subtle luminous-system cues
- and restrained symbolic depth

It must **not** feel like:

- a generic AI product
- a fantasy/lore product
- a mystical productivity app
- or a decorative "worldbuilding skin" placed on top of a normal interface

The symbolic layer must support:

- hierarchy
- object flow
- realm temperament
- meaningful transitions
- recurrence / carried value

It must not exist just to look distinctive.

---

## Relevant Prior Conclusions

The shell should become:

- a product-world frame

The realm-family model is:

- one shared material grammar with four realm temperaments

The signature surfaces are:

1. `Workspace`
2. `Prompt Preview`
3. `Keep`
4. kept-work focus in `Memory`
5. public result focus in `Community`
6. continuity focus in `Continuity`

The symbolic layer is supposed to be:

- subtle
- product-led
- ready for later Illustrator-built reinforcement

not:

- heavy
- ornamental
- or conceptually louder than the product itself

---

## What You Must Do

### 1. Reassess whether a symbolic layer is truly needed

Do not assume the answer is yes.
Ask:

- what real gap remains after shell, realm-family, and signature-surface work?
- can symbolism solve a real product problem here?
- or would it mostly risk noise?

### 2. If symbolism is justified, identify the most native symbolic logic

Look for symbolic meaning that is already inside MorpBase, such as:

- shaping
- carrying forward
- keeping
- returning
- circulation
- recurrence
- lineage
- thresholds
- activation
- public continuation

Do not invent mythology disconnected from the product.

### 3. Compare candidate symbolic directions

For example, consider possibilities like:

- line / trace / thread systems
- threshold / gate systems
- vessel / archive systems
- orbit / circulation systems
- resonance / echo systems
- geometric instrument cues
- or a synthesis

But only keep what really belongs.

### 4. Choose the strongest symbolic foundation

Explain:

- the core symbolic laws
- the motif family
- the emotional/product effect
- why this is right for MorpBase now

### 5. Define application boundaries

Be concrete about where symbolism should appear:

- shell frame
- engine strip
- realm markers
- signature focus surfaces
- transitions / thresholds
- continuity traces
- empty states
- object accents

And where it should **not** appear.

### 6. Define anti-drift rules

Make explicit how to prevent:

- decorative clutter
- fake mysticism
- over-ornamentation
- every surface becoming symbolic
- symbols replacing clarity

### 7. Make the output future-useful

The result should be usable later for:

- coded design translation
- Illustrator asset direction
- realm marker design
- custom icon/motif work
- higher-fidelity design passes

---

## Required Output Shape

Write a concrete decision document with sections like:

1. `The Real Symbolic Gap`
2. `Why A Symbolic Layer Is / Is Not Needed`
3. `Candidate Symbolic Directions`
4. `Chosen Symbolic Foundation`
5. `Core Symbolic Laws`
6. `Motif Family`
7. `Realm Translation`
8. `Where Symbols Should Appear`
9. `Where Symbols Must Not Appear`
10. `Illustrator / Asset Readiness`
11. `Anti-Theater Rules`
12. `Honest Conclusion`

Be decisive.
Be restrained.
Stay product-native.
