# MorpBase V2 Slice 2 Screen Map

## Main Screens Or States

1. `Memory Share Handoff`
   - a kept work item becomes shareable

2. `Community Discover`
   - the main public circulation surface for workflow results

3. `Public Result Focus`
   - one public work shown as a real MorpBase object, not a generic post

4. `Bring Into Memory`
   - a light import or keep-back moment that returns value into personal use

## Transitions

- `Memory -> Memory Share Handoff`
- `Memory Share Handoff -> Community Discover`
- `Community Discover -> Public Result Focus`
- `Public Result Focus -> Bring Into Memory`
- `Bring Into Memory -> Memory`
- `Public Result Focus -> Workspace` later, but not in the first coding pass

## What The Slice Is Really Proving

That public life can grow out of real MorpBase work without breaking the product center.

This slice is not proving a whole social system. It is proving that:

- kept work can become public
- public work can feel worth opening
- public work can return value back into the same engine
