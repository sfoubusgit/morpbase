# MorpBase V2 Response Direction Brief

## 1. Purpose

The purpose of this slice is:

- to prove the first calm creator-set response direction on public workflow results

In plain terms:

- a public result should be able to say:
  - take this line somewhere new
  - answer this with a different mood
  - keep the line but change the look

This matters because it turns public work from:

- inviting response in general

into:

- inviting a more legible kind of response

## 2. What Response Direction Should Mean

The first response direction slice in MorpBase should mean:

- **creator-set continuation guidance**

Not:

- a task
- a challenge prompt
- a contest brief
- narrative command

The right feeling is:

- this line is gently telling you what kind of answer it would welcome

That keeps the product:

- calm
- creator-led
- and close to real creation

## 3. Where It Should Attach First

The first slice should attach to:

### 1. Public Workflow Result Focus

Because this is where public work is already being read most deeply.

### 2. Publishing

Because creators should be able to see and lightly adjust the response direction where public work is managed.

## 4. What The First Slice Should Add

The first coded slice should add:

- a calm `Response Direction` panel on the selected public result
- a small set of creator-set direction choices
- a visible current direction on the public focus surface
- a lighter direction summary on the publishing surface

This should prove:

- public work can invite more legible participation
- without becoming a challenge system

## 5. What It Must Not Become

This slice must not become:

- a challenge prompt system
- task software
- contest framing
- narrative assignment

If it starts to feel like:

- `do this`
- `complete this brief`
- or `participate in this event`

then the slice has drifted.

## 6. Success Criteria

This slice succeeds if:

- public work feels more inviting
- the invited response feels clearer
- the product still feels calm
- and creation stays the center

This slice fails if:

- it feels pushy
- it feels game-like
- or it makes MorpBase feel like challenge software
