# Pressure Test: Celestial Pixel Portrait IDP Sets

## Date

18 March 2026

## Purpose

This document tests whether the three proposed `Celestial Pixel Portrait` IDP sets are actually distinct enough to justify being separate sets.

The goal is to prevent:

- cosmetic set inflation
- weak naming differences
- multiple sets that behave like the same baseline with tiny flavor drift

## Sets Under Review

- `Celestial Shrine`
- `Magical Idol`
- `Occult Pastel`

## Pressure Test Standard

An IDP set should only count as meaningfully distinct if it changes the workflow’s baseline identity in a way that a user can actually feel.

That means a valid set difference should affect at least some combination of:

- symbolic center
- emotional register
- accessory language
- decorative family
- likely secondary Pool compatibility

It should **not** only change:

- one adjective
- one vague tone word
- slight wording flavor with the same practical result

## Set 1: Celestial Shrine

### Claimed identity

- sacred
- floral
- serene
- devotional

### What it is trying to anchor

- shrine-like visual sanctity
- sacred symmetry
- floral celestial ornament
- divine calm

### What makes it distinct

Its strongest differentiation is:

- sacred softness rather than glamour
- floral / shrine ornamentation rather than ribbon or occult emphasis
- devotional calm rather than dramatic charm or uncanny mystery

### Pressure-test verdict

This set passes.

It has a clear visual and emotional center that is different from the others.

## Set 2: Magical Idol

### Claimed identity

- radiant
- glamorous
- charming
- polished

### What it is trying to anchor

- performance-like magical elegance
- ribbons and charm accents
- brighter sparkle energy
- more emotionally vivid and polished presentation

### What makes it distinct

Its strongest differentiation is:

- glamor and charm over sanctity
- accessory polish over shrine softness
- brighter, more performative magical-girl energy

### Pressure-test verdict

This set mostly passes.

It is meaningfully distinct from `Celestial Shrine`, but it is also the one most at risk of collapsing into “just a brighter celestial variant” if the supporting pool structure is weak.

So:

- conceptually valid
- but it will need strong supporting items to feel truly separate in practice

## Set 3: Occult Pastel

### Claimed identity

- arcane
- uncanny
- dreamy-dark
- mysterious

### What it is trying to anchor

- occult softness
- stranger crescent-based ornamentation
- eerie pastel glow
- quietly unsettling magical identity

### What makes it distinct

Its strongest differentiation is:

- mystery over serenity
- arcane oddness over polish
- uncanny glow over either shrine sanctity or magical-idol charm

### Pressure-test verdict

This set passes strongly.

It is clearly different in both emotional register and symbolic direction.

## Relative Separation Strength

### Strongest separation

- `Celestial Shrine` vs `Occult Pastel`

These are clearly different.

### Second strongest separation

- `Magical Idol` vs `Occult Pastel`

Also meaningfully different.

### Weakest separation

- `Celestial Shrine` vs `Magical Idol`

This is the pair most likely to blur if the workflow implementation is not strong enough.

That does not mean they are invalid.
It means they need stronger supporting differentiation in the actual pool structure.

## Main Risk

The main risk is not that the sets are conceptually bad.

The main risk is:

- `Magical Idol` and `Celestial Shrine` could feel too close in practice if they share too much accessory language, glow behavior, or emotional softness

So if we build these into a pool, we should deliberately differentiate:

- floral / shrine / sacred language
from
- ribbon / charm / polished magical-idol language

That distinction needs to be reinforced in:

- subject items
- mood items
- effects language
- optional secondary attachment points

## Important Conclusion

The sets are not all equally risky.

### Strong enough already

- `Celestial Shrine`
- `Occult Pastel`

### Viable but needs reinforcement

- `Magical Idol`

That is the most important finding from this pressure test.

## Recommended Adjustment Before Building

Before turning these into real pool structure, `Magical Idol` should probably be tightened slightly.

It should lean more clearly into:

- ribbon / jewel / charm accessory language
- polished magical presentation
- sweeter performative brightness

and less into:

- sacred floral serenity

That will make the three-set family much cleaner.

## Final Verdict

The three-set concept survives pressure-testing.

However:

- `Celestial Shrine` and `Occult Pastel` are already strong
- `Magical Idol` should be sharpened before structural implementation

So the correct outcome is:

- proceed
- but refine one set before building it
