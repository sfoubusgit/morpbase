# MorpBase V2 Shell Asset Integration Pilot Brief

## Intent

This pilot should test the first real integration of refined shell assets into the coded product.

The goal is not more visual complexity.

The goal is:

- a more singular shell
- a more authored top frame
- a more believable MorpBase product-world reading

## Integration Targets

Integrate only:

- refined top-frame joins
- refined brand support fragment
- refined engine joins
- refined shell knot
- refined primary realm separator

## What Must Stay True

The shell must still feel:

- calm
- structural
- restrained
- readable

It must not become:

- decorative
- louder than the product
- or detached from the coded hierarchy

## Honest Standard

If this works, the refined shell assets should feel native to the live product, not pasted onto it.
