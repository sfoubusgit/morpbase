# MorpBase V2 Threshold SVG Starter Kit Brief

## Intent

This kit should turn the threshold handoff into something you can actually open in Illustrator and start refining.

## Scope

Include only:

- one shared threshold family sketch
- `Keep`
- `Publish`
- `Use`
- `Activate`

Do not include yet:

- trace assets
- shell assets
- large placement boards
- decorative expansions

## Desired Feeling

The kit should feel:

- calm
- precise
- directional
- meaning-first

but not:

- ceremonial
- trophy-like
- mystical
- or logo-heavy

## Honest Standard

If this works, the threshold family should stop being only described and start being materially executable.
