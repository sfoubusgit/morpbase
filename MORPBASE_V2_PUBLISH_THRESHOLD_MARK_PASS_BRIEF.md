# MorpBase V2 Publish Threshold-Mark Pass Brief

## 1. The Real Publish Gap

`Publishing` is already structurally correct.

The gap is:

- it still feels slightly too much like release management
- and slightly too little like a public crossing

## 2. What Publish Should Feel Like

`Publish` should feel like:

- a line crossing from kept/private value into public life

The strongest reading is:

- released outward
- still connected inward

## 3. What Should Change In This Pass

### 1. The publishing desk should show a crossing reading

The desk should more clearly say:

- this is where ready work can cross into Community

### 2. The release action should lightly carry the threshold family

It should feel:

- more native
- not louder

### 3. The public crossing should still stay calmer than Keep

`Keep` is more intimate.

`Publish` should feel more outward, but not more dramatic.

## 4. What Should Stay Out

Do not add:

- launch-like messaging
- success celebration
- dashboard metrics
- promotional language
- decorative symbols

## 5. Success Condition

This pass succeeds if the honest reaction becomes:

- `Publish now feels more like a crossing into public life`
- `the threshold family still feels like one family`
- `Community still stays calm`
