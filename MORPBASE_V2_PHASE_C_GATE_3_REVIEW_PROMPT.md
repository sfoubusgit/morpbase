# MorpBase V2 Phase C Gate 3 Review Prompt

## Purpose

Review the `Phase C` Community prototype against its actual job.

Do not judge it by:

- polish
- completeness
- feature richness

Judge it by one question:

- does `Community` feel like the public life of real MorpBase work?

## Required Inputs

Use:

- `MORPBASE_V2_PHASE_C_COMMUNITY_PROTOTYPE_BRIEF.md`
- `MORPBASE_V2_PHASE_C_COMMUNITY_FLOW_MAP.md`
- `MORPBASE_V2_IMAGE_ROLE_ANALYSIS.md`
- `v2-prototypes/phase-c-community/index.html`
- `v2-prototypes/phase-c-community/styles.css`
- `v2-prototypes/phase-c-community/script.js`

## Review Criteria

Judge the slice on:

1. public loop legitimacy
2. visible proof without image-first drift
3. clarity between public results and reusable assets
4. creator grounding
5. import usefulness
6. return-to-core strength
7. whether Community still feels too much like a separate app

## Output

Write:

- `MORPBASE_V2_PHASE_C_GATE_3_REVIEW.md`

The review must include:

1. verdict
2. what clearly works
3. what still feels wrong or weak
4. the biggest risk if we move on too early
5. whether the slice should pass, conditionally pass, or iterate
6. the exact next move
