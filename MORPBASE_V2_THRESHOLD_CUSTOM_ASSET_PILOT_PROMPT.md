# MorpBase V2 Threshold Custom Asset Pilot Prompt

## Goal

Create the first real custom-asset pilot for the threshold family in MorpBase V2.

The purpose of this pilot is:

- to make the four real crossings feel more authored
- to keep the family clearly unified
- and to avoid turning threshold language into decorative symbolism

## Main Questions

### 1. What Should Be Added

- Which small refinements would make the threshold family feel more custom?
- What should be strengthened on the bands and actions?

### 2. What Must Stay Protected

- What would make the family too loud or emblem-like?
- What must still stay restrained?

### 3. Best Pilot Shape

- What is the smallest effective custom-asset bridge?
- Which real crossings should it touch?

## Output Format

Write the result as:

1. `Add`
2. `Protect`
3. `Pilot Shape`
4. `Honest Conclusion`
