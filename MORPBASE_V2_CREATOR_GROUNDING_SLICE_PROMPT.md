# MorpBase V2 Creator Grounding Slice Prompt

## Goal

Define the first controlled V2 slice that gives `Community` stronger creator grounding without turning MorpBase into a profile-first social app.

## Starting Point

The coded V2 already has:

- public workflow results
- public reusable assets
- stronger impact traces
- stronger object invitations

What the public side still lacks is:

- enough human grounding through creator practice

## Core Question

How should MorpBase V2 introduce creator grounding so public objects feel attached to a real creative practice, while still keeping the objects themselves central?

## Main Questions

### 1. Product Meaning

- What should a creator layer mean in MorpBase?
- How do creators feel human without becoming generic profiles?

### 2. First Slice Restraint

- What is the smallest creator-grounding slice that proves the idea?
- What should it include first?

### 3. Surface Placement

- Where should creator grounding show first?
- public object focus?
- a creator focus surface?
- a creator strip?

### 4. Discipline

- What would make this feel like real public practice?
- What would make it feel like generic social product behavior?

## Output Format

Write the result as:

1. `Purpose`
2. `What Creator Grounding Should Mean`
3. `Where It Should Show First`
4. `What The First Slice Should Add`
5. `What It Must Not Become`
6. `Success Criteria`

## Guardrails

- do not make creators the new center
- do not build a full social profile system
- do not weaken object-first Community logic
- keep the first slice calm, object-grounded, and practice-led
