# MorpBase V2 Realm Family Design Rules

## 1. The Real Realm-Family Gap

The current realms already belong structurally.

The gap is:

- they still feel more connected by logic than by inevitable family feeling

Plainly:

- they do not feel wrong
- but they do not yet feel like only one product world could contain all four

So this phase should not ask:

- how do we make each realm more interesting?

It should ask:

- how do we make each realm distinct in the right way while keeping them unmistakably of one world?

## 2. Realm-Entry Moments

### Entering `Workspace`

Should feel:

- active
- centered
- live
- instrument-like

### Shifting into `Memory`

Should feel:

- calmer
- more durable
- more collected
- but still clearly part of the same product world

### Entering `Community`

Should feel:

- more public
- more outward-facing
- more in circulation
- but still downstream from the same engine

### Entering `Continuity`

Should feel:

- quieter
- finer
- more recurrence-aware
- but still product-real and still related

### Moving between realms

Should feel:

- like changing mode inside one world

Not:

- like switching apps

## 3. Candidate Comparison

### Candidate A. One shared material grammar + four realm temperaments

Good:

- strongest balance
- protects the one-world feeling
- allows real differentiation without fragmentation

Judgment:

- strongest option

### Candidate B. Strong realm-by-realm visual separation

Good:

- distinct quickly

Bad:

- highest mini-app risk
- weakens inevitability

Judgment:

- wrong direction

### Candidate C. Mostly uniform product surfaces with light labels

Good:

- coherent

Bad:

- too flat
- weakens hierarchy and mood shifts

Judgment:

- too weak

### Candidate D. Symbolic identity first

Good:

- memorable

Bad:

- too early
- can create mythology before product family is settled

Judgment:

- support layer later, not the main family model

## 4. Chosen Family Model

The strongest family model is:

- **one shared material grammar with four realm temperaments**

Meaning:

- all four realms share the same MorpBase material language
- but each realm carries a different weight, pacing, and atmospheric pressure

That is the healthiest way to make the product feel:

- singular
- distinct
- authored
- and still integrated

## 5. Shared Family Rules

These should be true across all four realms:

### 1. Shared shape language

Panels, focus areas, and major surfaces should clearly belong to one family.

### 2. Shared material behavior

Light, depth, softness, edge behavior, and panel logic should feel related.

### 3. Shared composure

No realm should become noisy, frantic, or feed-chaotic.

### 4. Shared authored tone

Every realm should feel deliberate, calm, and product-real.

### 5. Shared object-carrying logic

The product should always feel like meaningful work is moving through different forms of value, not jumping between unrelated zones.

## 6. Per-Realm Rules

### Workspace

Must feel:

- most active
- most immediate
- most instrument-like
- most central

It should have:

- the strongest center of gravity
- the clearest live tension between shaping and preview
- the least visual hesitation

### Memory

Must feel:

- calmer
- more durable
- more layered
- more lived-in

It should have:

- more sense of collected work
- more sense of depth and return
- a bridge feeling, not a utility feeling

### Community

Must feel:

- more outward-facing
- more alive
- more public
- more circulated

It should have:

- stronger object presentation energy
- stronger outward orientation
- but still clear composure and discipline

### Continuity

Must feel:

- lighter
- finer
- quieter
- recurrence-aware

It should have:

- the most subtle symbolic pressure
- the least visual weight after Profile-level utility
- but enough distinction that it never feels accidental

## 7. Hierarchy Rules Across The Family

- `Workspace` must read as the clear center
- `Memory` must read as the strongest second pole
- `Community` must read as real but downstream
- `Continuity` must read as quieter but intentional

If those four weights stop being readable, the family rules are failing.

## 8. What This Locks

This locks that realm difference should come from:

- temperament
- pacing
- weight
- atmosphere

More than from:

- decorative difference
- separate design languages
- or heavy symbolic coding

## 9. What Should Still Wait

These should still wait:

- heavier motif systems
- realm-specific illustration systems
- deep symbolic overlays
- final ornamental character

Why:

- the family must be settled through shared material truth first

## 10. Honest Conclusion

The realms should not become more different by drifting apart. They should become more inevitable by behaving like one MorpBase material family with four clearly different temperaments. That is the strongest route to making V2 feel like one authored world instead of several good zones.
