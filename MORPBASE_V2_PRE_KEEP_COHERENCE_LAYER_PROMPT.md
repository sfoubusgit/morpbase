# MorpBase V2 Pre Keep Coherence Layer Prompt

Design the first light `pre-keep coherence` layer inside `Refine And Keep` for MorpBase V2.

The goal is:

- make Phase 4 feel less compressed
- strengthen the bridge between preview trust and `Keep`
- keep the final phase calm and non-bureaucratic

Focus on:

- what the line now clearly holds together
- what should be reflected back to the user before crossing into `Memory`
- how to make the last phase feel more meaningful without adding weight

Judge:

- what kind of coherence reading is healthy
- whether it should be chips, a compact reading, or one guided reflection
- how it should relate to the existing finishing note

Avoid:

- scores
- percentages
- checklists
- validation bureaucracy
- another large freeform field

Prefer:

- one compact guided layer
- clear emotional usefulness
- a stronger bridge into `Keep`
