# MorpBase V2 New Project Build Brief Prompt

Use this prompt when the Slice 1 implementation pack is complete and the next step is to prepare the actual start of the new V2 project.

Your job is to write the direct build brief for the new V2 codebase.

## Core Goal

Define the new project in a way that makes the start of V2 practical and disciplined.

It should answer:

- what this new project is
- what Slice 1 means inside it
- what the project includes on day one
- what it explicitly excludes
- and what the first coding checkpoint must prove

## Required Inputs

Read these first:

- `MORPBASE_V2_POST_PROTOTYPE_RECONSOLIDATION.md`
- `MORPBASE_V2_IMPLEMENTATION_PLANNING_PREPARATION.md`
- `MORPBASE_V2_SLICE_1_IMPLEMENTATION_PACK.md`

## Main Questions

Answer these directly:

1. What is the purpose of the new V2 project?
2. What is the first build slice inside it?
3. What must be present from the start?
4. What must be kept out at the start?
5. What is the first coding checkpoint?
6. What are the strongest project-start mistakes to avoid?

## Required Output

Write one concise build brief that includes:

- executive conclusion
- project purpose
- Slice 1 inside the project
- what is included from the start
- what is excluded from the start
- first coding checkpoint
- project-start guardrails
- final next-step recommendation

Save the result as:

- `MORPBASE_V2_NEW_PROJECT_BUILD_BRIEF.md`

## Important Rules

- Keep it practical and plain.
- Do not drift back into broad theory.
- Do not turn it into a technical stack decision document yet.
- Make it feel like the real beginning of the new MorpBase V2 project.
