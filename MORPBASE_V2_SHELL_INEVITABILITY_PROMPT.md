# MorpBase V2 Shell Inevitability Prompt

## Goal

Create the `shell inevitability brief` for MorpBase V2.

This is the first concrete artifact inside the whole-product inevitability phase.

Its job is to answer:

- what the top-level MorpBase shell must feel like
- what it must communicate immediately
- what it must stop feeling like
- and what the next shell-strengthening work should actually target

## Why This Matters

The current coded V2 shell is already:

- correct
- structured
- more authored than before

But it is still not fully inevitable.

Plainly:

- it works as a shell
- but it does not yet feel like only MorpBase could have this shell

## Important Inputs

Use these as the main grounding:

- `MORPBASE_V2_CURRENT_STATE_FREEZE_AND_INSPECTION.md`
- `MORPBASE_V2_WHOLE_PRODUCT_INEVITABILITY_PHASE.md`
- `MORPBASE_V2_TOP_LEVEL_SHELL_ANALYSIS.md`
- `MORPBASE_V2_DESIGN_UNIVERSE_PREPARATION.md`
- `MORPBASE_V2_CODED_DESIGN_TRANSLATION_BRIEF.md`
- the current coded top shell in `morpbase-v2/src/App.tsx`

## Required Method

1. restate the real shell gap in plain language
2. use real product-entry moments first
3. compare multiple shell-inevitability approaches
4. choose the strongest shell direction now
5. define what the shell brief must lock
6. explain what should still wait

## Product Moments To Use

At minimum:

1. first visual entry into the product
2. recognizing `Workspace` as the obvious center
3. understanding `Memory` as the second home
4. seeing `Community` as real but not a competing center
5. feeling `Continuity` as lighter but still belonging
6. reading the engine strip and shell as one world instead of several sections

## Candidate Approaches To Compare

### Candidate A. Stronger authored shell frame

Example:

- stronger brand block
- stronger shell composition
- stronger asymmetry at a glance

### Candidate B. More atmospheric realm identity

Example:

- shell and header behavior shift more clearly by active realm

### Candidate C. Stronger engine-strip integration

Example:

- make the engine strip feel more inseparable from the shell

### Candidate D. More decorative distinctiveness

Example:

- more motifs
- more ornament
- more visual flair

### Candidate E. Utility simplification first

Example:

- reduce shell pieces
- make it cleaner and quieter

## Questions That Must Be Answered

1. What is the true shell gap now?
2. What must the shell communicate immediately?
3. What should make the shell feel authored rather than assembled?
4. What specific shell areas most affect inevitability?
5. What should still wait until later phases?

## Guardrails

- do not add new product systems
- do not confuse decoration with inevitability
- do not flatten hierarchy
- do not make Community feel equal to Workspace
- do not over-symbolize Continuity
- keep the shell meaning-led

## Deliverable

Write a `shell inevitability brief` that includes:

1. the real shell gap
2. real product-entry moments
3. candidate comparison
4. chosen shell direction
5. shell areas to strengthen
6. what should wait

Tone:

- plain
- honest
- product-focused
