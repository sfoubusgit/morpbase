# MorpBase V2 Design-Character Tightening Prompt

## Goal

Define the next coded tightening phase for V2 now that the product logic is strong enough.

This is not a prompt for:

- adding new systems
- adding more participation mechanics
- or doing the final full design universe

It is a prompt for defining the strongest next coded pass that will make the current V2 feel:

- more authored
- more integrated
- more distinctive
- more unmistakably MorpBase

## Starting Point

The coded V2 now already has:

- a real center
- a real second home
- a real public life layer
- a real lighter continuity layer
- and several meaningful loops

The current gap is:

- product character
- hierarchy expression
- atmospheric continuity

## Main Questions

### 1. Purpose

- What exactly should this tightening phase improve?

### 2. Strongest Targets

- Which surfaces should be strengthened first?
- shell?
- bridge surfaces?
- object focus surfaces?
- public side?
- continuity side?

### 3. What Must Stay Out

- What would count as fake polish or feature drift?

### 4. Success Criteria

- What should feel different after this pass if it works?

## Output Format

Write the result as:

1. `Purpose`
2. `What This Phase Should Strengthen`
3. `Strongest Coded Targets`
4. `What Must Stay Out`
5. `Success Criteria`
