# MorpBase V2 Coded Design Translation Prompt

## Goal

Define the next phase after Slice 4 as a **design-translation and experience-strengthening pass for the coded V2**.

This phase should answer:

- how to make the current coded V2 feel more unmistakably like MorpBase
- how to strengthen product character without drifting into generic polish
- how to translate the design-universe preparation into the actual new codebase

## Starting Point

The coded V2 now has:

- `Workspace`
- `Memory`
- `Community`
- `Continuity`
- stronger cross-realm coherence

So this phase is **not** about discovering the product structure again.
It is about expressing the already-correct structure more strongly.

## Questions

### 1. Product Character

- What makes the current coded V2 still feel too prototype-like?
- What should be strengthened so it feels more product-real and more distinctly MorpBase?

### 2. Design Translation

- Which parts of the MorpBase design universe should now enter the codebase first?
- What is the right first translation layer before any full art-direction pass?

### 3. Scope Discipline

- What belongs in this phase?
- What should wait for a later fuller design pass?

## Output Format

Write the result as:

1. `Purpose`
2. `What This Phase Should Strengthen`
3. `Recommended Design Translation Areas`
4. `What Must Stay Out`
5. `Success Criteria`

## Guardrails

- do not reopen product structure
- do not turn this into vague polish language
- do not pretend the final design universe is being fully implemented yet
- do not let design strengthening flatten the asymmetrical product hierarchy
