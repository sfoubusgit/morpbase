# MorpBase V2 Threshold Refinement V1 Brief

## Intent

This pass should turn the threshold kit from:

- usable starter vectors

into:

- a more authored first refinement set

## Scope

Refine only:

- the shared threshold family
- `Keep`
- `Publish`
- `Use`
- `Activate`

Also include:

- one overview board

Do not include:

- trace assets
- shell assets
- UI mockups
- larger symbolic spread

## Desired Feeling

The result should feel:

- more precise
- more unified
- more believable as real MorpBase crossing language

but not:

- ceremonial
- trophy-like
- or louder than the product

## Honest Standard

If this works, the threshold family should begin to feel like it has a real authored vector language, not only a starter-kit approximation.
