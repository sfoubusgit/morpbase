# MorpBase V2 Shell Refinement V1 Prompt

## Goal

Create the first refined shell asset set after the baseline freeze.

The purpose of this step is:

- to move beyond starter vectors into a more authored shell language
- to keep refinement structural and restrained
- and to make the shell family feel closer to a real Illustrator-ready direction

## Main Questions

### 1. What Should Be Refined

- Which shell pieces gain the most from a first refinement pass?
- What should become more precise or more singular?

### 2. What Must Stay Protected

- What would make the shell feel ornamental or too premium-coded?
- What should remain calm and structural?

### 3. Best Refinement Shape

- What is the smallest useful refined set?
- What should be delivered alongside the refined assets?

## Output Format

Write the result as:

1. `Refine`
2. `Protect`
3. `Refinement Shape`
4. `Honest Conclusion`
