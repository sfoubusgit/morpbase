# MorpBase V2 Slice 2 Build Brief

## Goal

Prove that MorpBase work can begin to live publicly without breaking the workflow-centered engine.

## Include

- a light `Community` realm entry
- one `Discover` surface for public workflow results
- a path from kept work in `Memory` into public circulation
- one public result page or result focus state
- one clear path back into personal use

## Exclude

- creator system depth
- reusable public assets as a full second public class
- challenges
- reward systems
- collaboration systems
- continuity-linked public behavior
- marketplace-like mechanics

## Main Loop

`Memory -> Publish / Share -> Discover -> Open Result -> Bring Value Back`

## First Checkpoint Question

`Does Community already feel like the public life of real MorpBase work, or too much like a separate content layer?`
