# MorpBase V2 Shell Refinement V1 Brief

## Intent

This pass should turn the shell kit from:

- usable starter vectors

into:

- a more authored first refinement set

## Scope

Refine only:

- top-frame joins
- brand support fragment
- engine joins
- shell knot
- primary realm separator

Also include:

- one overview board

Do not include:

- threshold assets
- trace assets
- UI mockups
- larger shell inventions

## Desired Feeling

The result should feel:

- more precise
- more singular
- more product-real

but not:

- ornate
- luxurious for its own sake
- or louder than the product

## Honest Standard

If this works, the shell should begin to feel like it has a real authored vector language, not only a starter-kit approximation.
