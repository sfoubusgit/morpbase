# MorpBase V2 Trace SVG Starter Kit Brief

## Intent

This kit should turn the trace handoff into something you can actually open in Illustrator and start refining.

## Scope

Include only:

- one shared trace family sketch
- center arrival trace
- memory trace
- public trace
- continuity trace

Do not include yet:

- threshold assets
- shell assets
- larger connector maps
- decorative spread across ordinary panels

## Desired Feeling

The kit should feel:

- fine
- quiet
- readable
- consequence-led

but not:

- loud
- graph-like
- ceremonial
- or ornamental

## Honest Standard

If this works, the trace family should stop being only described and start being materially executable.
