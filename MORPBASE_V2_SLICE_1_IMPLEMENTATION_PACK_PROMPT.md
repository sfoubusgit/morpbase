# MorpBase V2 Slice 1 Implementation-Pack Prompt

Use this prompt after the Slice 1 planning chain is complete.

Your job is to compress the Slice 1 planning artifacts into one practical implementation-planning pack for the new V2 codebase.

## Core Goal

Create one document that makes it easy to start the new project by answering:

- what Slice 1 is
- what documents govern it
- what the build order is
- what is frozen
- and what the first coding effort should stay focused on

## Required Inputs

Read these first:

- `MORPBASE_V2_SLICE_1_BUILD_BRIEF.md`
- `MORPBASE_V2_SLICE_1_SCREEN_MAP.md`

## Main Questions

Answer these directly:

1. What is the purpose of the Slice 1 implementation pack?
2. Which documents should be treated as the active Slice 1 control set?
3. What is the shortest plain description of Slice 1?
4. What is frozen versus still flexible inside Slice 1?
5. What should the first coding effort avoid?

## Required Output

Write one concise implementation pack document that includes:

- purpose
- active control docs
- short Slice 1 definition
- frozen parts
- flexible parts
- build order summary
- anti-drift reminders
- final next-step recommendation

Save the result as:

- `MORPBASE_V2_SLICE_1_IMPLEMENTATION_PACK.md`

## Important Rules

- Keep it compact and practical.
- Do not reopen broader V2 theory.
- Make it easy to use as the real starting pack for the new codebase.
