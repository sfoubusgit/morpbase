# MorpBase V2 Public Object Richness Slice Prompt

## Goal

Define and build the first controlled public extension of the richer V2 object model.

This slice should let `Community` begin to reflect that the private side now has more than one meaningful object type.

## Starting Point

The coded V2 already has:

- kept work
- reusable assets
- public workflow results
- continuity lines

The next natural public growth is:

- the first public life of reusable assets

## Main Questions

### 1. Product Meaning

- What should a public reusable asset feel like in MorpBase?
- How is it different from a public workflow result?

### 2. Community Discipline

- How can `Community` reflect the richer object model without turning into a broad many-object platform?
- How can the public side stay object-led and calm?

### 3. Integration

- How should public reusable assets grow out of private reusable assets?
- How should they still return value inward?

## Output Format

Write the result as:

1. `Purpose`
2. `What This Slice Should Add`
3. `What Makes Public Reusable Assets Different`
4. `What It Must Not Become`
5. `Success Criteria`

## Guardrails

- do not turn Community into a feed
- do not create a broad public marketplace
- do not let public reusable assets overshadow workflow results
- keep the slice narrow, calm, and object-led
