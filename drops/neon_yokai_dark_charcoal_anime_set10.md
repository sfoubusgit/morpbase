# Neon Yokai × Dark Charcoal Anime — 10-Prompt Set (Z-Image-Turbo)

The dark, moody charcoal-anime treatment of Neon Yokai. Deep blacks, low-key
lighting, monochrome.

**Posting workflow (so image↔prompt matching is painless):**
- **Best:** render so the prompt is embedded in the PNG (ComfyUI/A1111/Forge do
  this) → CivitAI auto-fills each prompt on upload, no manual matching.
- **Fallback:** save each render under its **`Save as:`** filename below (set it
  as your tool's filename prefix, or rename after). The filename then tells you
  exactly which prompt it is.

**Shared negative:** `text, watermark, signature, lowres, blurry, extra fingers,
deformed hands, color, vibrant, clean cel shading, bright, white background,
3d render, photograph`

**Settings:** Turbo → ~8 steps, CFG ~1.0–1.5.

**Style tail:** *a dark moody charcoal drawing of an anime character, heavy
graphite and charcoal with deep velvety blacks and dramatic low-key lighting,
smudged hand-drawn shading, a dark shadowy charcoal-filled background, strong
contrast, visible paper grain, monochrome greyscale, ominous and atmospheric,
not clean cel coloring.*
