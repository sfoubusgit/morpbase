# Dust Run × Comic / Graphic Novel — 20-Prompt Set (Z-Image-Turbo)

A Style Lab remix: the Dust Run universe rendered in the `style_lab_comic` look.
Tight, front-loaded prompts leaning into comic conventions — dramatic angles,
action lines, high-contrast staging.

**Shared negative:** `text, watermark, signature, speech bubble, lowres, blurry,
extra fingers, deformed hands, 3d render, photograph, soft pastel, washed out`

**Settings:** Turbo → ~8 steps, CFG ~1.0–1.5. Wides 1248×832, portraits 832×1248.

**Style tail (kept on every prompt):** *bold comic-book graphic-novel art, heavy
black inks, flat color with halftone shading, dramatic high-contrast lighting,
punchy and graphic.*
