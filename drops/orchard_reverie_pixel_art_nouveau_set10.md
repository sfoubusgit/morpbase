# Orchard Reverie × Art Nouveau × Pixel Core — 10-Prompt Set (Illustrious)

The first Orchard Reverie drop. Fruit-bonded wardens rendered as Mucha decorative panels in modern indie pixel art — figure + halo disk + ornate botanical border, all pixel-rendered. Re-uses the validated **Pixel Art Nouveau** recipe (first proven on Solarpunk Bloom).

---

**Recipe — Pixel Art Nouveau (Illustrious)**
- **Model family:** Illustrious
- **Checkpoint:** `illustriousXL_v01.safetensors` or `hosekiLustrousmix_illustNoobaiEPS11V2.safetensors`
- **LoRA:** `new_pixel_core-ILL.safetensors` @ **0.9** (drop to 0.7 if it overbakes)
- **Triggers (front):** `newpixelcore, pixel art, many details`
- **Quality (front):** `masterpiece, best quality, amazing quality, very aesthetic, absurdres, newest`
- **Sampler:** Euler a · **CFG 5** · **28 steps**
- **Resolution:** 832×1216 portrait / 1216×832 landscape

**Shared negative:**
```
worst quality, low quality, lowres, blurry, jpeg artifacts, bad anatomy, deformed hands, extra fingers, watermark, signature, text, photoreal, 3d render, harsh shadows, dark gloomy palette, anti-aliased smooth lines
```

**Style tail (kept on every prompt):** `art nouveau, mucha style, decorative panel, ornate floral border, halo disk behind head, flowing organic lines, gold accents, soft warm pastel palette, golden hour`
