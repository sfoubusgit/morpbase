This document must become the new governing reference for V2 before blueprint work begins.

- what is now truly frozen
- what is only directionally frozen
- what is still flexible
- what is explicitly deferred
- what future V2 work must not violate

- a true successor to V1

- a stronger expression of MorpBase's real heart

The master reassessment has already concluded:

- product truth is mostly strong enough

- broad concept expansion should slow down
