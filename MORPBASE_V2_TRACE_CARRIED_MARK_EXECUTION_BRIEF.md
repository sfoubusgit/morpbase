# MorpBase V2 Trace / Carried-Mark Execution Brief

## 1. Trace Family Purpose

If thresholds say:

- a line crossed

then traces should say:

- something remained
- something travelled
- something can still be read

The trace family exists to support:

- carried value
- visible continuity
- readable public consequence
- and return-path legitimacy

## 2. Shared Trace Grammar

The trace family should be built from:

- fine carried-line fragments
- small nodes
- segmented continuations
- quiet directional residue

What it should feel like:

- evidence that a line left a readable mark behind it

What it should not feel like:

- decorative connectors
- map diagrams
- circuitry
- or ornament-heavy lineage graphics

## 3. Memory Trace Reading

`Memory` should express:

- what endured
- what survived
- what still gives the kept line identity

So Memory traces should feel:

- durable
- settled
- lightly sedimented

This is the best place for the first coded bridge because:

- the meaning is clearest here
- the risk of over-staging is lowest
- and it strengthens the private core loop directly

## 4. Community Trace Reading

`Community` should express:

- what travelled outward
- what sparked response
- what created a public family

So Community traces should feel:

- circulating
- readable
- but still calm

They should not turn into:

- social graph visuals
- popularity decoration
- or feed energy

## 5. Continuity Trace Reading

`Continuity` should express:

- what repeats
- what remains recognizable
- what proves recurrence

So Continuity traces should feel:

- finest
- quietest
- most precise

They must stay lighter than Community and far lighter than any story-system feeling.

## 6. Preview / Arrival Support

The trace family can also support:

- Preview trust
- arrival readings
- return cues

But only lightly.

Those should stay secondary uses for now.

## 7. Code-Led vs Illustrator-Led Split

### Keep code-led for now

- location of trace blocks
- spacing and hierarchy
- structural grouping
- relationship between traces and supporting copy

### Best Illustrator-ready parts

- refined trace fragments
- node variants
- continuity recurrence marks
- public response connectors
- calmer carried-line accents

## 8. Anti-Overgrowth Rules

The trace family must not:

- appear on every card
- turn ordinary panels into motif panels
- compete with hierarchy
- become pseudo-storytelling
- or make the product look busier

If the user feels:

- "there are traces everywhere"

instead of:

- "this line clearly left evidence"

then the family is wrong.

## 9. Best First Coded Bridge

The healthiest first coded bridge is:

- **Memory carried-trace deepening**

Why:

- `Memory` is where endurance is easiest to read
- it reinforces the second-home feeling
- and it prepares the product for stronger Community and Continuity trace execution later

## 10. Practical Next Sequence

The healthiest sequence is:

1. Memory carried-trace pass
2. Community public-trace and response-lineage pass
3. Continuity recurrence-trace pass
4. lighter Preview / arrival-trace calibration

## 11. Honest Conclusion

The trace family is the right next symbolic layer because it is the most natural companion to the now-established threshold family.

Thresholds say:

- a line crossed

Traces should now say:

- a line left readable value behind it
