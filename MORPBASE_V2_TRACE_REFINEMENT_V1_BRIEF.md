# MorpBase V2 Trace Refinement V1 Brief

## Intent

This pass should turn the trace kit from:

- usable starter vectors

into:

- a more authored first refinement set

## Scope

Refine only:

- shared trace family
- center arrival trace
- memory trace
- public trace
- continuity trace

Also include:

- one overview board

Do not include:

- threshold assets
- shell assets
- UI mockups
- larger connector maps

## Desired Feeling

The result should feel:

- more precise
- more residue-like
- more singular
- still quieter than the threshold family

but not:

- heavier
- more decorative
- more illustrative for its own sake
- or detached from the product

## Honest Standard

If this works, the trace family should begin to feel like a real authored MorpBase vector language for carried value and readable consequence.
