# Set-Aware Item List: Celestial Pixel Portrait

## Date

18 March 2026

## Purpose

This note maps the current `Celestial Pixel Portrait` pool items against the three proposed IDP sets.

It exists to keep the pool and the future Multi IDP Set concept aligned.

## Shared Core

These item families are shared by all three sets and should remain broadly valid:

- most `Style` items
- most `Lighting` items
- most `Composition` items

These form the stable family identity.

## Current Structural Reading

This pool is already usable under the current single-IDP system.

At the same time, it is now structured in a way that should transition cleanly into a future Multi IDP Set system because:

- shared family items already exist
- set-sensitive items already exist
- the strongest variation is concentrated in:
  - `Subjects`
  - `Mood`
  - `Effects`

## Best Future Migration Path

If Multi IDP Sets are implemented later:

1. keep the current shared initiative stack as the common family core
2. attach set-specific support phrases to:
   - `Celestial Shrine`
   - `Magical Idol`
   - `Occult Pastel`
3. use this mapping as the basis for set-sensitive recommendations and future secondary-pool compatibility
