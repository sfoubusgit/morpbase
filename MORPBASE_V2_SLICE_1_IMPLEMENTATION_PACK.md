# MorpBase V2 Slice 1 Implementation Pack

## 1. Purpose

This pack exists to make Slice 1 easy to start.

Its job is to reduce the current planning chain into one practical entry point for the new V2 codebase.

It should help us avoid:

- scattered planning
- reopening settled questions
- and drifting back into V1-style feature-by-feature building

## 2. Short Slice 1 Definition

Slice 1 is:

- **the real `Workspace + Memory` core loop of MorpBase V2**

Plainly:

- create in `Workspace`
- `Keep` meaningful work
- land in `Memory`
- reopen / branch / continue back into live creation

That is the first real product slice.

## 4. What Is Frozen Inside Slice 1

These things should be treated as fixed unless a real contradiction appears:

- Slice 1 is `Workspace + Memory`
- `Workspace` is the center
- `Memory` is the second home
- the core loop is:
  - create
  - keep
  - return
- `Prompt Preview` is part of the live center
- `Keep` must feel meaningful, not administrative
- `Memory` must not feel like storage
- images act as proof, not center
- the shell must stay asymmetrical

## 5. What Is Still Flexible Inside Slice 1

These things are still open for later planning or coding choices:

- exact component breakdown
- exact visual styling details
- exact wording of some small UI text
- exact persistence/storage mechanics
- exact internal implementation patterns

These should be solved in code planning and build work, not by reopening the product truth.

## 6. Build Order Summary

Slice 1 should be built in this order:

1. `Workspace` core
2. `Keep` emergence
3. `Memory` entry
4. return loop
5. design strengthening
6. tightening pass

The most important practical rule is:

- do not try to build the whole slice evenly all at once

## 7. Anti-Drift Reminders

When building Slice 1, keep these reminders active:

### 1. No V1 carryover by convenience

### 2. No early `Community` or `Continuity` leakage

### 3. No generic AI/SaaS shell drift

### 4. No over-modeling too early

### 5. No storage-like Memory behavior

### 6. No treating `Prompt Preview` as a separate heavy object

## 8. The First Coding Focus

The first coding effort should focus on:

- making the live `Workspace` believable
- making `Keep` feel earned
- making `Memory` feel alive
- and making return into `Workspace` feel like continuation

If those four things do not feel right, Slice 1 is not alive yet.
