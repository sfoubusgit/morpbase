# MorpBase V2 Illustrator-Oriented Asset Map

## 1. Purpose

This map exists to answer one practical question:

- what custom visual assets would most help MorpBase feel like only MorpBase?

The goal is not to decorate the product.

The goal is to strengthen:

- shell identity
- threshold feeling
- trace / carried-value logic
- and the six signature surfaces

## 2. Main Asset Families

### Family A. Shell joins and frame markers

What they are:

- top-frame dividers
- frame-edge join marks
- shell-to-engine connectors
- realm-group separators

What they should communicate:

- one held product frame
- one engine
- crafted structure

Where they belong:

- top frame
- realm navigation grouping
- shell-engine join area

Why this family matters:

- this is the strongest whole-product identity gain

### Family B. Brand-mark system

What they are:

- refined `MB` mark directions
- inner-line treatments
- mark-to-frame connection cues
- small supporting brand fragments

What they should communicate:

- authored product identity
- confidence
- instrument-like seriousness

Where they belong:

- brand anchor
- very light supporting shell moments

Why this family matters:

- the current brand anchor is stronger now, but still not final

### Family C. Threshold marks

What they are:

- `Keep` crossing mark
- `Publish` crossing mark
- `Use In Workspace` mark
- `Activate` mark

What they should communicate:

- this is a meaningful crossing
- value moved
- a line changed state

Where they belong:

- threshold panels
- focus-action areas
- shell/top-frame support later if needed

Why this family matters:

- threshold feeling is one of the most MorpBase-native symbolic opportunities

### Family D. Trace / carried-mark system

What they are:

- fine carried-line fragments
- small trace nodes
- response / lineage connectors
- continuity recurrence marks

What they should communicate:

- this line travelled
- this value endured
- recurrence is readable

Where they belong:

- continuity focus
- response lineage
- public line family
- kept-work and public-result trace blocks

Why this family matters:

- this is the strongest symbolic family after thresholds

### Family E. Realm accent markers

What they are:

- light realm-specific marker language
- small cues for `Memory`, `Community`, and `Continuity`

What they should communicate:

- same product world
- different temperament

Where they belong:

- realm nav
- shell atmosphere support
- selective signature-surface framing

Why this family matters:

- realm distinction needs support, but must stay restrained

### Family F. Signature-surface framing cues

What they are:

- subtle edge cues
- focus-surface frame fragments
- direction / proof / return / circulation / recurrence frame hints

What they should communicate:

- this is one of the defining MorpBase places

Where they belong:

- `Workspace`
- `Prompt Preview`
- `Keep`
- kept-work focus
- public result focus
- continuity focus

Why this family matters:

- these are the places where MorpBase identity should feel strongest

## 3. Priority Tiers

### Tier 1. Highest priority

- Shell joins and frame markers
- Brand-mark system
- Threshold marks

Why:

- these create the biggest gain in product-world feeling

### Tier 2. Strong second priority

- Trace / carried-mark system
- Signature-surface framing cues

Why:

- these deepen the product where MorpBase becomes most itself

### Tier 3. Later / lighter priority

- Realm accent markers

Why:

- useful
- but easiest to overdo
- and less important than shell, thresholds, and traces

## 4. What Should Stay Code-Led For Now

These should stay mostly code/CSS-led for now:

- layout
- spacing
- core hierarchy
- state logic
- engine-strip logic
- object flow
- most card and panel styling

The asset layer should support the product.
It should not replace the product structure.

## 5. What Should Wait

These should wait until later:

- large illustration scenes
- realm-specific art systems
- empty-state worldbuilding scenes
- expanded motif spread across ordinary panels
- challenge / storyline / reward imagery

Those would be too early and would risk product theater.

## 6. Practical Creation Order

The healthiest creation order is:

1. shell joins and frame markers
2. refined brand-mark system
3. threshold marks
4. trace / carried-mark system
5. signature-surface framing cues
6. light realm accent markers

## 7. Best First Deliverables

The best first actual Illustrator deliverables would be:

### 1. Shell kit

- top-frame divider set
- shell-engine join set
- realm-group separator set

### 2. Brand kit

- refined `MB` mark
- alternate micro-mark
- mark-to-frame support fragments

### 3. Threshold kit

- `Keep`
- `Publish`
- `Use`
- `Activate`

### 4. Trace kit

- carried-line fragments
- node marks
- continuity trace pieces
- public response connectors

## 8. Honest Conclusion

The strongest custom asset layer for MorpBase is not:

- illustration first
- nor decorative branding first

It is:

- shell
- thresholds
- traces

Those are the asset families most native to what MorpBase actually is.
