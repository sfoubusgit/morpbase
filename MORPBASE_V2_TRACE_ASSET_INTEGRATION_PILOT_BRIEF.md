# MorpBase V2 Trace Asset Integration Pilot Brief

## Intent

This pilot should test the first real integration of refined trace assets into the coded product.

The goal is not more visible symbolism.

The goal is:

- more believable carried value
- more authored residue language
- more MorpBase-native consequence reading

## Integration Targets

Integrate only:

- refined center arrival trace
- refined memory trace
- refined public trace
- refined continuity trace

inside:

- the live trace bands
- the center arrival / preview arrival surfaces

## What Must Stay True

The traces must still feel:

- calm
- fine
- residue-like
- quieter than thresholds

They must not become:

- graph-like
- louder
- more connected for their own sake
- or more decorative than meaningful

## Honest Standard

If this works, the trace family should feel like one quiet authored layer inside the live product.
