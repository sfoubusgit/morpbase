# MorpBase V2 Shell Identity Execution Brief

## 1. Shell Identity Goal

The shell should now become:

- a more singular product-world frame

not:

- a header with well-designed supporting pieces

The core job of the next shell pass is to make the top of MorpBase feel like:

- one authored frame
- one engine reading
- and one clear realm hierarchy

## 2. Top-Frame Execution Targets

The top frame already works.

What it still lacks is:

- stronger singularity
- stronger join logic
- and stronger authored edge language

So the next shell pass should strengthen:

- custom frame separators
- quieter but clearer joining lines
- stronger asymmetrical frame reading
- a more deliberate relationship between frame edge, realm state, and engine state

What this should feel like:

- the product is held inside one crafted instrument frame

What it should not feel like:

- more chrome
- thicker containers
- ornamental borders

## 3. Brand / Brand-Mark Execution Targets

The brand block should feel less like:

- a neat product label

and more like:

- the first anchor of the MorpBase world

The next pass should strengthen:

- the authority of the mark
- the relationship between the mark and the frame
- the feeling that the mark belongs to the shell structure, not just the left side of the header

Practical direction:

- strengthen the mark-to-frame connection
- make the mark feel more embedded
- give the brand copy a little more authored hierarchy

## 4. Shell Compass Execution Targets

The shell compass is useful, but it still risks reading like:

- a nice explanatory note

The next pass should make it feel more like:

- a calm orientation instrument inside the shell

Strengthen:

- its relationship to the engine strip
- its sense of purpose
- its internal hierarchy

Reduce:

- the feeling that it is merely descriptive text in a box

## 5. Realm-Nav Execution Targets

The realm nav should more clearly express:

- `Workspace` as center
- `Memory` as second pole
- `Community` as legitimate outward realm
- `Continuity` as real but lighter

The next pass should strengthen:

- realm weighting
- active-realm atmosphere
- the difference between primary group and orbit group
- calmer but more unmistakable realm markers

The nav should not become:

- louder
- busier
- or more app-like

It should become:

- more inevitable

## 6. Engine-Strip Integration Targets

This is one of the most important shell jobs.

The engine strip should feel even less like:

- a strong secondary panel set

and more like:

- the readable operating logic of the product frame

The next pass should strengthen:

- joins between the shell and engine strip
- the feeling that the engine strip belongs inside the same frame event
- the MorpBase-specific reading of movement through value

This is the part of the shell that most clearly expresses:

- make
- keep
- return
- circulate
- recur
- re-enter

So it should feel special without becoming louder.

## 7. What Can Stay Code-Led For Now

These can stay mostly code-led in the next pass:

- structural layout
- realm switching logic
- engine state logic
- current hierarchy model
- active-realm tint system

The next pass should build on those, not replace them.

## 8. What Should Become Illustrator-Ready Later

The strongest later custom asset opportunities in the shell are:

- top-frame dividers and joins
- custom realm markers
- engine-strip join marks
- subtle threshold / carry marks around the top frame
- a stronger authored brand-mark language

These should not all be forced into code first.
They should be prepared as later custom asset opportunities.

## 9. What Should Not Happen

The next shell pass should not become:

- generic premium polish
- ornamental visual drama
- heavier panels
- more shell sections
- stronger explanation text

If the shell gets louder instead of more singular, the pass fails.

## 10. Practical Next Move

The next coded/design move should focus on:

1. tighter shell-to-engine joins
2. stronger realm-nav weighting
3. calmer but more authored top-frame separators
4. a more embedded brand anchor

That is the healthiest next pass because it improves:

- singularity
- hierarchy
- and authored identity

without reopening product structure or adding features.

## 11. Honest Conclusion

The shell is now strong enough that the next move is not invention.

It is:

- making the shell feel more like only MorpBase could wear it

That should be done through:

- stronger joins
- clearer weighting
- calmer but more authored marks

not through more visual noise.
