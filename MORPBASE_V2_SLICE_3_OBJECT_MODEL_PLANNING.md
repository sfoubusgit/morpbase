# MorpBase V2 Slice 3 Object Model Planning

## Minimum Objects

- `Kept Work`
  - already exists from Slice 1

- `Continuity Entity`
  - first implementation lane:
    - `Character`

## Relationship

`Continuity Entity` should attach to multiple `Kept Work` items as recurring sameness.

For this first slice it only needs:

- name
- short identity reading
- visual anchor summary
- linked kept-work appearances
- one activation path back into `Workspace`

## Still Out Of Scope

- multi-entity continuity systems
- relationship graphs
- storyline objects
- public continuity circulation
- complex lineage systems
- broad identity frameworks
