# MorpBase V2 Threshold Asset Integration Pilot Brief

## Intent

This pilot should test the first real integration of refined threshold assets into the coded product.

The goal is not more visual drama.

The goal is:

- more unified crossings
- more authored threshold reading
- more MorpBase-native action thresholds

## Integration Targets

Integrate only:

- refined `Keep`
- refined `Publish`
- refined `Use`
- refined `Activate`

inside:

- the threshold bands
- the four real crossing actions

## What Must Stay True

The thresholds must still feel:

- calm
- meaning-first
- readable
- restrained

They must not become:

- ceremonial
- badge-like
- trophy-like
- or louder than the product

## Honest Standard

If this works, the crossings should feel more like one real authored family inside the live product.
