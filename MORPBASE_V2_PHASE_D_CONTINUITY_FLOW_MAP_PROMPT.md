# MorpBase V2 Phase D Continuity Flow Map Prompt

## Purpose

Turn the Phase D brief into one clear low-complexity flow map.

The flow map should show the smallest Continuity loop that can prove:

- one recurring entity feels real
- appearances make sameness understandable
- images support continuity as evidence
- activation back into `Workspace` feels meaningful

## Required Inputs

Use:

- `MORPBASE_V2_PHASE_D_CONTINUITY_PROTOTYPE_BRIEF.md`
- `MORPBASE_V2_CONTINUITY_REALM_MODEL_ANALYSIS.md`
- `MORPBASE_V2_IMAGE_ROLE_ANALYSIS.md`
- `IDENTITY_SYSTEMS_REALM_ANALYSIS.md`

## Output

Write:

- `MORPBASE_V2_PHASE_D_CONTINUITY_FLOW_MAP.md`

The flow map should define:

1. the ordered sequence of states
2. what the user sees in each state
3. what each state must communicate
4. what the user can do
5. what the state must prove
6. the main exit from each state

## Quality Bar

The flow must make it possible to answer:

- does Continuity feel like a real MorpBase realm?

If the flow feels like:

- a character gallery
- an identity admin screen
- a hidden archive filter
- or early worldbuilding theater

then it is wrong.
