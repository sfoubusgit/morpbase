# MorpBase V2 Object Invitations Review Prompt

## Goal

Judge whether the first object-invitations slice made MorpBase feel more alive without making it louder or busier.

## Starting Point

The coded V2 now uses calmer invitation language on the main object focus surfaces.

Those invitations make actions feel more like:

- continue
- branch
- use
- bring inward
- carry forward

And less like:

- generic utility buttons

## Main Questions

### 1. Product Feel

- Do objects now feel more alive?
- Do their next actions feel more natural?

### 2. Restraint

- Did the slice stay calm?
- Or did it become too app-like or too CTA-heavy?

### 3. Engine Fit

- Does this strengthen the same object engine?
- Does it prepare later collaboration, playfulness, and challenge systems without becoming them?

### 4. Next Move

- Is this enough for now?
- Or does it still need tightening before another growth step?

## Output Format

Write the result as:

1. `Verdict`
2. `What Now Works`
3. `Remaining Caution`
4. `Best Next Move`
