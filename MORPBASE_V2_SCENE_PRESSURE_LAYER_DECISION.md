# MorpBase V2 Scene Pressure Layer Decision

## Decision

The first `Stage The Image` deepening move should be:

- one light `scene pressure` layer beside framing

## What This Means

`Phase 3` now has:

- `Framing And Focus`
- `Scene Pressure`

The scene-pressure field stays small and curated:

- `Still`
- `Charged`
- `Ceremonial`
- `Confronting`

## Why This Wins

The next weak spot was no longer:

- subject
- or look

It was:

- staging compression

So the strongest answer was not:

- more framing options
- or more keep complexity

It was:

- one second staging dimension

## What This Layer Does

It helps the user decide:

- how the image meets the viewer
- how much force or stillness it carries

Without turning Phase 3 into:

- environment design
- composition software
- scene writing

## Keep Threshold Rule

The core keep threshold still stays:

- subject
- look
- framing

That is important.

The new scene-pressure layer strengthens staging, but it does not make the threshold heavier.

## Plain Conclusion

This is the right Phase 3 move because it makes staging feel more like:

- real image pressure

instead of:

- one framing pick before Keep
