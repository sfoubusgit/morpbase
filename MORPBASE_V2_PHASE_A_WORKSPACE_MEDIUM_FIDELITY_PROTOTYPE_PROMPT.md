- Do **not** drift into implementation details

## Method

### 1. Start with real interaction moments

Write at least 5 Phase A moments such as:

- landing in the real Workspace
- beginning through the guided first-flow layer
- making the first meaningful shaping move
- seeing Preview become trustworthy
- arriving at `Keep` / `Save`

For each, explain what the medium-fidelity prototype must make testable.

### 2. Translate the low-fi flow into interactive scope

Define:

- which states are required
- which transitions must be clickable/testable
- what kind of response should be shown

### 3. Define mock vs real behavior

Be explicit about:

- what should be simulated
- what should feel live
- what can stay placeholder

### 4. Define the review gate

State exactly what the medium-fidelity prototype must prove before Phase B can begin.
