# MorpBase V2 Lightweight Manual Realm QA Brief

Goal:
- define the smallest useful manual inspection rhythm for the support realms

Target realms:
- `Memory`
- `Community`
- `Continuity`

What the manual pass should judge:
- does `Memory` still feel like a second home, not storage
- does `Community` still feel object-led, not feed-led
- does `Continuity` still feel light but real
- do all three still support the stronger `Workspace` center

Guardrails:
- keep it lightweight
- keep it product-feel focused
- avoid turning this into a large QA matrix
