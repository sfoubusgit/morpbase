# MorpBase V2 Slice 1 Hardening Brief

## Goal

Make the first V2 loop feel more durable, believable, and worth returning to, without broadening the slice beyond `Workspace + Memory`.

## Hardening Priorities

1. `Local persistence`
   - the kept-work loop should survive refresh or re-entry

2. `Stronger reopen / branch behavior`
   - returning from `Memory` should feel more like continuation and less like reloading a form

3. `Kept-work depth`
   - a kept item should carry enough shape to feel meaningfully worth reopening

4. `Light design tightening`
   - only where it helps the core loop feel more product-real

## What Stays Out

- Community behavior
- Continuity behavior
- publishing
- collaboration
- rewards
- challenges
- storylines
- advanced asset systems
- heavy backend or cloud architecture

## The First Hardening Move

`Add disciplined local persistence for kept work and the active return path`

Why:

- it makes the slice feel more real immediately
- it deepens `Memory` without broadening it
- it strengthens the idea that good work can stay alive here
- it supports stronger reopen / branch behavior naturally
