# MorpBase V2 Design-Universe Execution Preparation Prompt

## Purpose

Prepare the actual execution layer for the MorpBase V2 design universe.

This phase should translate the already chosen direction:

- crafted creative instrument
- archival memory
- restrained luminous-system depth

into concrete execution targets.

## Important Constraint

Do not redesign the product from scratch.

Assume these are already frozen:

- product hierarchy
- realm ownership
- object flow
- one-engine truth

This phase is about:

- execution preparation

not:

- reopening product fundamentals

## Required Method

Start with concrete product moments.

### Moment 1. First entry into Workspace

Ask:

- what custom shell/world cues should be visible immediately?

### Moment 2. Keep threshold crossing

Ask:

- what should make this feel like a crossing instead of a styled save box?

### Moment 3. Entering Memory

Ask:

- what gives `Memory` its durable, living, collected feeling?

### Moment 4. Opening a public result

Ask:

- what makes `Community` feel outward-facing but still MorpBase?

### Moment 5. Entering Continuity

Ask:

- what makes recurrence feel fine-grained and special without becoming theater?

## Required Output

Produce a practical execution-preparation brief with:

1. shell identity targets
2. realm-family execution targets
3. signature-surface execution targets
4. symbolic trace / threshold / carried-mark execution targets
5. Illustrator-ready asset opportunities
6. what should stay in code-only territory for now
7. what should wait until later

## Decision Standard

The result should make the next phase easier to execute by answering:

- what must be custom
- what must stay restrained
- what will matter most to product inevitability

## Tone

Keep the result practical, plain, and execution-oriented.
