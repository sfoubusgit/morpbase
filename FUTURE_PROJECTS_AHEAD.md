# Future Projects Ahead

## Purpose

This document collects the major future-facing MorpBase ideas that have emerged so far.

It is not:

- a strict roadmap
- a build order
- a promise that all of these should be implemented

It is:

- a structured view of the larger future project space

## Important Principle

These ideas are not all equally near-term.

Some are:

- realistic next-feature candidates

Some are:

- medium-term expansion paths

Some are:

- long-term vision ideas that should be preserved carefully but not built soon

## Near-Term Candidates

### 1. Prompt Sets

Purpose:

- group related saved prompts into meaningful creative collections

Why it matters:

- adds context and continuity to saved prompts
- improves archive clarity
- naturally strengthens `Quick Save`

Current state:

- concept defined
- MVP defined
- implementation plan defined
- first MVP implemented and pushed

Status:

- active near-term feature lane

### 2. Quick Save

Purpose:

- quickly capture prompts created or modified outside MorpBase

Why it matters:

- supports real external iteration workflows
- becomes much stronger when paired with Prompt Sets

Current state:

- concept defined
- MVP documented
- not implemented

Status:

- plausible next prompt-management expansion

### 3. Gothic Character Portrait Elasticity Test

Purpose:

- validate whether the new gothic pool behaves like a real primary host workflow

Why it matters:

- tests the current system through real use
- checks family coherence and IDP separation

Current state:

- official pool built and pushed
- test doc created
- practical test not yet completed

Status:

- active validation thread

## Medium-Term Expansion Candidates

### 4. Secondary Pool Growth

Purpose:

- expand the primary/secondary pool system carefully

Why it matters:

- enables more modular composition
- adds variation without replacing primary identity hosts

Current state:

- concept defined
- one real secondary pool exists:
  - `Sacred Emblems and Handheld Relics`

Status:

- ongoing expansion area, but not urgent immediately

### 5. Prompt Library Growth

Purpose:

- continue improving saved-prompt workflow in practical ways

Possible directions:

- Prompt Sets refinement
- Quick Save
- better save/browse relationships
- stronger retrieval patterns

Current state:

- now clearly emerging as one of MorpBase’s stronger practical lanes

Status:

- medium-term product-strengthening area

## Conceptual But Not Recommended To Build Yet

### 6. Character Identity System

Purpose:

- reusable cross-workflow character identity layer

Why it matters:

- continuity of characters across different workflows
- reusable subject identity above niche pools

Current state:

- heavily explored
- master concept exists
- architecture fit explored
- MVP defined

Status:

- serious concept
- not recommended as next implementation

### 7. Reusable Identity Framework

Purpose:

- larger framework that could contain:
  - character identity
  - outfit identity
  - other future identity objects

Why it matters:

- points toward reusable creative entity systems

Current state:

- conceptually framed
- strong boundary notes exist

Status:

- long-range conceptual architecture
- not a current build lane

### 8. Identity Entities Separate From Builder

Purpose:

- preserve the idea that reusable identity entities should not be flattened into normal Builder/Territory category items

Why it matters:

- keeps identity systems distinct and meaningful

Current state:

- concept note created

Status:

- important boundary, not a build lane by itself

## Long-Term Vision Ideas

### 9. Shared Storylines

Purpose:

- support continuity across prompts, identities, environments, and potentially multiple users

Why it matters:

- points toward structured collaborative continuity creation

Current state:

- captured as a long-term vision note

Status:

- very exciting
- very dangerous if pursued too early
- preserve only

### 10. Iteration Systems As Methodologies

Purpose:

- recognize repeatable prompt-iteration methods as named systems

Why it matters:

- reframes iteration as a methodology, not just casual prompting
- could one day support more disciplined creative experimentation

Current state:

- long-term concept note created

Status:

- intellectually strong
- not a near-term feature lane

### 11. Challenges And Reward Systems

Purpose:

- introduce structured creative exercises and possibly restrained rewards

Why it matters:

- could motivate experimentation
- could teach workflows
- could create progression and engagement

Current state:

- only at idea level
- not yet formally explored

Status:

- promising
- needs careful unpacking before formalization

## Ongoing Structural Concerns

### Territory Friction

Territories remain:

- useful
- but still conceptually heavier than ideal

Current state:

- several clarity passes already done
- still an important product concern

Status:

- ongoing refinement area

### Live Workflow Validation

MorpBase still needs repeated proof that:

- workflows actually hold up in use
- strong Pools can do more work than new systems
- complexity is justified by practical value

Status:

- ongoing core responsibility

## Honest Conclusion

The future project space around MorpBase is now large enough that it needs to be seen in layers:

### Immediate / near-term

- Prompt Sets
- Quick Save
- gothic elasticity testing

### Medium-term

- prompt-library growth
- careful secondary pool expansion

### Long-term

- Character Identity
- Reusable Identity Framework
- Shared Storylines
- Iteration Methodologies
- Challenges / Rewards

That layered view is healthier than treating all new ideas as equally actionable.
