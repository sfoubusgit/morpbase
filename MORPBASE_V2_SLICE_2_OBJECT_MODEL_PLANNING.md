# MorpBase V2 Slice 2 Object Model Planning

## Minimum Objects

- `Kept Work`
  - already exists from Slice 1

- `Public Workflow Result`
  - the smallest new public object needed for Slice 2

## Relationship

`Public Workflow Result` should be created from `Kept Work`.

It should carry:

- title
- short public framing
- proof image
- lightweight source link back to the originating kept work

## Not First-Class Yet

- creator objects with depth
- public reusable assets
- comments
- likes or reward systems
- challenges
- continuity-linked public objects
- collaboration objects
