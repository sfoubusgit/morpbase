# MorpBase V2 Slice 2 Interaction Map

## Main Loop Behavior

1. `Share` should feel like releasing meaningful work, not posting casually.
2. `Discover` should feel alive, but still object-led and calm.
3. `Public Result Focus` should make the work feel reusable, inspectable, and worth bringing back.
4. `Bring Into Memory` should feel like value returning into personal practice, not a random copy action.

## What Must Feel Right

- sharing feels earned
- the public result still feels like MorpBase work
- images help prove value, but do not become the real object
- the loop back into personal use feels obvious

## Failure Signs

- `Discover` feels like a generic feed
- the public result feels like a normal content card with text under it
- import feels like a detached download move
- the public side feels like a mini app that does not need `Workspace` or `Memory`
