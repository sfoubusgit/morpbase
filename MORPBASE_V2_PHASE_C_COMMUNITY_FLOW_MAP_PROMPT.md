# MorpBase V2 Phase C Community Flow Map Prompt

## Purpose

Turn the Phase C brief into one clear low-complexity flow map.

The flow map should show the smallest public loop that can prove:

- real work can become public
- public objects feel worth opening
- creator grounding feels real
- import turns public value back into personal value
- the loop returns into the core product

## Required Inputs

Use:

- `MORPBASE_V2_PHASE_C_COMMUNITY_PROTOTYPE_BRIEF.md`
- `MORPBASE_V2_IMAGE_ROLE_ANALYSIS.md`
- `MORPBASE_V2_PUBLIC_OBJECT_MODEL_ANALYSIS.md`
- `MORPBASE_V2_PUBLIC_OBJECT_PAGE_MODEL_ANALYSIS.md`
- `MORPBASE_V2_CREATOR_PAGE_MODEL_ANALYSIS.md`

## Output

Write:

- `MORPBASE_V2_PHASE_C_COMMUNITY_FLOW_MAP.md`

The flow map should define:

1. the ordered sequence of states
2. what the user sees in each state
3. what each state must communicate
4. what the user can do
5. what the state must prove
6. the main exit from each state

## Quality Bar

The flow must make it possible to answer:

- does Community feel like the public life of real MorpBase work?

If the flow feels like:

- browse-only community
- image feed
- social profile loop
- or detached publishing

then it is wrong.
