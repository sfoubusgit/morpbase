# MorpBase V2 Meaningful Sharing And Impact Prompt

## Goal

Define the first controlled V2 slice that makes object impact more legible.

This slice should make MorpBase better at showing what happened to meaningful objects after they entered the engine.

It should not build:

- collaboration systems
- challenge systems
- reward systems
- storyline systems

It should only build the first safer bridge toward those futures.

## Starting Point

The coded V2 already has:

- `Workspace`
- `Memory`
- `Community`
- `Continuity`
- `Kept Work`
- `Reusable Assets`
- `Public Workflow Results`
- `Public Reusable Assets`

The current product can already:

- create
- keep
- reuse
- release publicly
- import publicly
- return value inward
- show recurrence

What it does not yet show strongly enough is:

- what impact an object has had across that flow

## Core Question

How should MorpBase show meaningful sharing, branching, reuse, import, release, and carry-forward signals on its core objects without becoming noisy, generic, or dashboard-like?

## Main Questions

### 1. Product Meaning

- What should count as a meaningful impact signal?
- Which signals are strong enough to show?

### 2. Surface Placement

- Where should those signals appear first?
- Which surfaces matter most:
  - object cards
  - focus panels
  - Memory views
  - Community views
  - Continuity views

### 3. Discipline

- How do these signals stay calm and product-native?
- What would make them feel like cheap metrics?

### 4. First Slice Restraint

- What is the narrowest first coded slice that still proves the idea?

## Output Format

Write the result as:

1. `Purpose`
2. `What Counts As Meaningful Impact`
3. `Where It Should Show First`
4. `What The First Slice Should Add`
5. `What It Must Not Become`
6. `Success Criteria`

## Guardrails

- do not introduce points, likes, or currency
- do not create an analytics dashboard
- do not turn object cards into metric stacks
- keep the signals tied to real product meaning
- make the result strengthen the engine rather than distract from it
