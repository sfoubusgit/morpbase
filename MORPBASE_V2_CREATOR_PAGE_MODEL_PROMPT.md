# MorpBase V2 Creator Page Model Prompt

You are analyzing **MorpBase V2** as a **completely new rebuilt product**, not as an iteration layered onto V1.

Your task is to determine the strongest **creator page model** for V2 Community.

This is **not** a generic profile-page exercise.

The creator page must be analyzed as a serious product surface inside the broader V2 whole-product model already established:

- `Workspace` is the dominant product center
- `Memory` is the strong second pole
- `Community` is a real public realm
- `Continuity` is real but lighter in first-wave
- Community already centers on:
  - `Discover`
  - `Creators`
  - `Publishing`
- Community already uses a two-primary-object public model:
  1. `Public Workflow Results`
  2. `Public Reusable Assets`
- Public object pages already use a shared utility-rich grammar

You must decide:

- what a V2 creator page should fundamentally be
- how it should organize around the two public object types
- how much creator identity vs public work vs public activity should show
- how it should stay object-grounded instead of becoming a generic profile
- how it should support later public vitality without overbuilding first-wave

## Critical Constraints

- Treat V2 as a **fresh rebuild**
- Do **not** preserve V1 structures by default
- Do **not** design a generic social/media profile page
- Do **not** let creator identity overshadow public objects
- Do **not** make creator pages thin account wrappers around uploads
- Do **not** fragment creator pages into too many equal sections
- Do **not** let creator pages feel detached from `Discover`, `Publishing`, and public object pages

## Method

### 1. Start with real-life usage drafts first

Write at least 5 realistic creator-page usage drafts such as:

- user discovers a creator from a public workflow result
- user wants to understand what kind of creator this is
- user wants to browse only reusable assets from one creator
- user wants to decide whether to follow a creator
- creator wants their page to represent their practice well
- later public challenge/event participation needs to appear without hijacking the page

For each draft, explain what structural demands it creates.

### 2. Generate multiple creator-page model candidates

Create at least 5 genuinely different creator-page models, for example:

- generic profile-first model
- activity/feed-first model
- portfolio/gallery model
- practice-page model
- asymmetric object-led model

You may create better alternatives if they are stronger.

For each candidate, explain:

- what the page fundamentally is
- what sections it emphasizes
- what it gets right
- where it fails

### 3. Compare the candidates seriously

Explicitly judge:

- clarity
- object-grounding
- creator meaning
- public usefulness
- support for follow/discovery behavior
- fit with Community structure
- fit with the two public object model
- resistance to generic-social-profile drift
- headroom for later challenge/bounty/event vitality

### 4. Choose the strongest model or a synthesis

Lock the best creator page model for MorpBase V2.

### 5. Make the result concrete

Define:

- what the creator page fundamentally is
- the recommended section/order model
- what is always visible
- what is lens-based
- how `Public Workflow Results` and `Public Reusable Assets` should appear
- how much creator biography/identity should show
- what public activity belongs on the page in first-wave
- what later-growth signals may appear later

## Output Requirements

Write the final result as:

`MORPBASE_V2_CREATOR_PAGE_MODEL_ANALYSIS.md`

Structure it with:

1. Executive Conclusion
2. Real-Life Usage Drafts
3. Candidate Creator Page Models
4. Comparison
5. Chosen Creator Page Model
6. Recommended Page Structure
7. Relationship To Public Objects
8. Role Of Creator Identity
9. First-Wave vs Later Growth
10. Final Judgment

The final answer should be decisive, reflective, and product-structural.
