# MorpBase V2 Slice 3 Screen Map

## Main Screens Or States

1. `Continuity Home`
   - a light realm entry that explains recurring sameness through real work

2. `Entity Focus`
   - one recurring character shown as a real continuity object

3. `Appearances`
   - the same character traced through multiple kept works

4. `Activate Into Workspace`
   - the live payoff of using continuity back in creation

## Transitions

- `Memory -> Continuity Home`
- `Continuity Home -> Entity Focus`
- `Entity Focus -> Appearances`
- `Entity Focus -> Activate Into Workspace`
- `Activate Into Workspace -> Workspace`

## What The Slice Is Really Proving

That MorpBase can explain and reuse recurring sameness across work without turning continuity into a heavy separate management layer.
