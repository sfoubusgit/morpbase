# MorpBase V2 Trace Custom Asset Pilot Prompt

## Goal

Create the first real custom-asset pilot for the trace family in MorpBase V2.

The purpose of this pilot is:

- to make the trace family feel more truly authored
- to keep it quieter than the threshold family
- and to avoid turning traces into decorative connectors or a social-graph visual layer

## Main Questions

### 1. What Should Be Added

- Which small refinements would make the trace family feel more custom?
- Where should those refinements appear first?

### 2. What Must Stay Protected

- What would make the family too visible or too ornamental?
- What must still stay restrained?

### 3. Best Pilot Shape

- What is the smallest effective custom-asset bridge?
- Which trace surfaces should it touch?

## Output Format

Write the result as:

1. `Add`
2. `Protect`
3. `Pilot Shape`
4. `Honest Conclusion`
