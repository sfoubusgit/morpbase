# MorpBase V2 Slice 1 Interaction Map Prompt

Use this prompt after the Slice 1 screen map has been defined.

Your job is to define how the first V2 build slice should behave in lived use.

## Core Goal

Turn the Slice 1 screen map into a plain, practical interaction map that answers:

- how the user moves through the slice
- what each transition feels like
- what must happen for the slice to feel alive
- and what would make it feel technical, cold, or incomplete

## Required Inputs

Read these first:

- `MORPBASE_V2_SLICE_1_BUILD_BRIEF.md`
- `MORPBASE_V2_SLICE_1_SCREEN_MAP.md`
- `MORPBASE_V2_INTERACTION_BLUEPRINT.md`
- `MORPBASE_V2_PHASE_A_WORKSPACE_PROTOTYPE_BRIEF.md`
- `MORPBASE_V2_PHASE_B_MEMORY_PROTOTYPE_BRIEF.md`

## Main Questions

Answer these directly:

1. What is the lived user path through Slice 1?
2. What should each screen or state feel like?
3. What are the critical transition behaviors?
4. What feedback must the product give at each stage?
5. What are the strongest failure signs?

## Required Output

Write one concise interaction map that includes:

- executive conclusion
- the main lived path
- screen-by-screen behavior
- transition behavior
- required feedback signals
- failure signs
- final next-step recommendation

Save the result as:

- `MORPBASE_V2_SLICE_1_INTERACTION_MAP.md`

## Important Rules

- Keep the slice centered on `Workspace -> Keep -> Memory -> return`.
- Keep the language plain and product-focused.
- Do not drift into technical implementation detail.
- Make it easy to tell whether the slice would feel like MorpBase or not.
