# MorpBase V2 Slice 3 Build Brief

## Goal

Prove that recurring sameness can become a meaningful part of MorpBase without turning the product into a heavy identity-management system.

## Include

- a light `Continuity` realm entry
- one recurring entity type:
  - `Character`
- one `Appearances` reading through real kept work
- one activation path back into `Workspace`
- one sense that the same entity can live across multiple works

## Exclude

- broad identity frameworks
- multiple entity types
- relationship graphs
- storyline systems
- collaboration systems
- reward systems
- public continuity behavior
- complex editing or taxonomy layers

## Main Loop

`Memory work -> Continuity reading -> Activate into Workspace -> continue the line`

## First Checkpoint Question

`Does Continuity already feel like recurring sameness with real payoff, or still too much like identity storage in nicer clothes?`
