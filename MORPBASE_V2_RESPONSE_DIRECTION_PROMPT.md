# MorpBase V2 Response Direction Prompt

## Goal

Define the first restrained `response direction` slice for the coded V2.

This is not a prompt for challenge prompts, tasks, events, or contests.

It is a prompt for the smallest calm layer that proves:

- a public workflow result can express what kind of response it invites
- that direction still feels creator-set and object-led
- and MorpBase can deepen participation without becoming challenge software

## Starting Point

The coded V2 already has:

- public circulation
- continuation invitations
- playful version invitations
- response lineage visibility
- public line family reading

What it still lacks is:

- a clearer creator-set direction for what kind of response a public result is inviting

## Main Questions

### 1. Product Meaning

- What should response direction mean in MorpBase?
- Why is a calm response direction stronger than a challenge prompt right now?

### 2. Object Fit

- Which public objects should support this first?
- should it attach mainly to public workflow results?

### 3. First Slice Restraint

- What is the smallest first slice that proves the idea?
- where should it appear first?

### 4. Discipline

- What keeps this creator-set and calm?
- What would make it drift into challenges, contests, or social tasking?

## Output Format

Write the result as:

1. `Purpose`
2. `What Response Direction Should Mean`
3. `Where It Should Attach First`
4. `What The First Slice Should Add`
5. `What It Must Not Become`
6. `Success Criteria`
