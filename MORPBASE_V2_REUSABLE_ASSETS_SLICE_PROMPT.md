# MorpBase V2 Reusable Assets Slice Prompt

## Goal

Define and build the first real `Reusable Assets` slice inside the coded V2 product.

This slice must grow naturally out of the current engine:

- `Workspace`
- `Memory`
- `Community`
- `Continuity`

It must deepen reuse without creating a second product center.

## Starting Point

The current coded V2 already has:

- kept work in `Memory`
- public release through `Community`
- recurring sameness through `Continuity`

The strongest next object type is:

- reusable shaping material

## Main Questions

### 1. Product Meaning

- What is a `Reusable Asset` in MorpBase V2?
- How is it different from kept work?
- Why is it useful?

### 2. Integration

- How should reusable assets grow out of kept work?
- How should they return value into `Workspace`?
- How should they prepare for later public circulation without building that whole layer yet?

### 3. Scope Discipline

- What should this first slice include?
- What must stay out because it would turn into a generic library or snippet system?

## Output Format

Write the result as:

1. `Purpose`
2. `What A Reusable Asset Is`
3. `What This Slice Should Include`
4. `What It Must Not Become`
5. `Success Criteria`

## Guardrails

- do not create a second product center
- do not turn this into a file manager
- do not turn this into generic prompt snippets
- keep `Memory` as the bridge layer
- keep `Workspace` as the center
