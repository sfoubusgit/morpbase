# MorpBase V2 Slice 1 Build Brief

## 1. Executive Conclusion

Slice 1 should be:

- **the real V2 `Workspace + Memory` core loop**

This is the right first build slice because it proves the most important thing first:

- MorpBase is a live creative engine
- not just an editor
- not just a prompt tool
- and not yet a broad platform

If Slice 1 works, the new V2 project already feels like the beginning of the real product.
If it fails, later `Community` or `Continuity` work will not rescue it.

## 2. Slice Definition

Slice 1 is the smallest real version of MorpBase V2 that proves:

- live creation happens in `Workspace`
- good work can be `Kept`
- kept work becomes alive in `Memory`
- and the user can continue from that work naturally

Plainly:

- create
- keep
- return

That is the Slice 1 heart.

## 3. Included Screens And States

Slice 1 should include these real product surfaces:

### 1. Workspace

Must include:

- the V2 shell with `Workspace` dominant
- the main authoring surface
- persistent `Prompt Preview`
- the guided but non-wizard first-flow behavior
- a visible `Keep` moment

### 2. Keep Handoff

Must include:

- the transition from a live session into kept value
- a clear feeling that the result is now durable

### 3. Memory Home

Must include:

- the landing view after keeping
- the sense that work is still alive here
- a strong return path into `Workspace`

### 4. Saved Work Focus

Must include:

- at least one kept result that can be reopened or branched

### 5. Return To Workspace

Must include:

- branch / reopen / continue movement back into live creation

Slice 1 does **not** need the full Memory realm yet.
It needs the part of `Memory` that proves the core return loop.

## 4. Included Object Loop

The object loop that must be real in Slice 1 is:

1. active workflow session in `Workspace`
2. meaningful result emerges
3. result is `Kept`
4. kept work lands in `Memory`
5. kept work can be reopened / branched / continued
6. user returns into `Workspace`

This loop is what makes Slice 1 feel like MorpBase instead of:

- a nice prompt builder
- or a saved-prompts utility

## 5. Must-Have Capabilities

These capabilities must exist for Slice 1 to count as real:

### Must have

- asymmetric top-level shell
- live `Workspace`
- persistent `Prompt Preview`
- image-backed proof inside the live loop where needed
- meaningful `Keep` action
- `Memory Home`
- at least one real kept-work object
- reopen / branch / continue flow
- frozen V2 naming
- calm, product-real hierarchy

## 6. Explicit Exclusions

These things should stay out of Slice 1:

### Exclude for now

- `Community`
- `Continuity`
- publishing
- import flows
- creator pages
- challenge systems
- reward systems
- collaboration mechanics
- storyline mechanics
- deep reusable-asset systems
- advanced capture flows
- profile depth beyond basic shell presence

These are important later.
They are not necessary to prove Slice 1.

## 7. Success Criteria

Slice 1 succeeds only if these are true:

### 1. Workspace feels like the real center

### 2. Prompt Preview builds trust early

### 3. Keep feels meaningful, not administrative

### 4. Memory already feels like a second home, not storage

### 5. Reopen / branch / continue feels natural

### 6. The whole slice already feels like MorpBase

Not:

- an editor demo
- a wireframe in code
- or the shell of a future product

## 8. Main Risks

### 1. Building too little

If Slice 1 is too small, it will feel like scaffolding instead of product truth.

### 2. Building too much

If Slice 1 starts absorbing `Community`, `Continuity`, or other future pressures, it will lose focus.

### 3. Falling back into V1 habits

If the slice borrows too much old structure by convenience, the new project will begin with the wrong gravity.

### 4. Generic design drift

If Slice 1 is coded as a standard AI/SaaS shell, MorpBase will lose distinctiveness before the design universe ever gets a chance.

## 9. Final Next-Step Recommendation

The next artifact after this brief should be:

- **the Slice 1 screen map**

That should define, very concretely:

- the exact screens
- the exact states
- the exact transitions

inside the `Workspace + Memory` build slice.

## 10. Final Judgment

`Slice 1 should be the real Workspace + Memory core loop of MorpBase V2: strong enough to feel like the beginning of the true product, disciplined enough to avoid early realm inflation, and focused enough to prove the heart before anything broader is built.`
