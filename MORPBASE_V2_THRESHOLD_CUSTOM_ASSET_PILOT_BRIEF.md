# MorpBase V2 Threshold Custom Asset Pilot Brief

## Intent

This pilot should prove that the threshold family can become more truly authored without losing:

- clarity
- restraint
- meaning-first reading

## Scope

Touch only:

- the four threshold bands
- the four real crossing actions

Meaning:

- `Keep`
- `Publish`
- `Use In Workspace`
- `Activate`

Do not turn this into:

- a bigger shell pass
- a trace-family pass
- a wider action-button redesign
- or ornamental symbol growth

## Desired Feeling

The result should feel:

- more unified
- more custom
- more MorpBase-native

but not:

- more ceremonial
- more badge-like
- or more dramatic

## Honest Standard

If this pilot works, the four crossings should feel more like:

- one authored threshold family

and less like:

- four good coded threshold treatments
