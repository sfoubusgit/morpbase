# MorpBase V2 Trace Refinement V1 Prompt

Create the first refined trace asset set after the starter-kit baseline.

The goal is not to invent a new symbolic family.

The goal is to take the existing trace family and make it:

- more precise
- more believable
- more materially authored

while keeping it:

- quiet
- fine
- readable
- consequence-led

## Scope

Refine only:

- shared trace family
- center arrival trace
- memory trace
- public trace
- continuity trace

Also include:

- one overview board

Do not include:

- threshold assets
- shell assets
- UI mockups
- larger connector maps
- decorative spread into ordinary product surfaces

## Desired Feeling

The result should feel:

- more precise
- more residue-like
- more singular
- more believable as real MorpBase trace language

but not:

- louder
- graph-like
- ceremonial
- or ornamental

## Honest Standard

If this works, the trace family should begin to feel like a real authored vector layer for MorpBase, not only a useful starter-kit approximation.
