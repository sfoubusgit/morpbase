# MorpBase V2 Preview / Arrival-Trace Calibration Brief

## Intent

This pass should make the center say, a little more clearly:

- this line came from somewhere
- it arrived carrying readable value
- and `Prompt Preview` is where that carried value gets tested again

## Scope

Touch only:

- `Arrival Reading`
- `Prompt Preview`
- light return-entry cues inside the center

Do not turn this into:

- another wider shell pass
- another surface-family redesign
- or a new symbolic system

## Desired Feeling

The result should feel:

- more joined
- more readable
- more MorpBase-native

but not:

- busier
- louder
- or more decorative

## Honest Standard

If this pass works, the center should feel more like:

- the place where carried value becomes live again

and less like:

- the same workspace no matter how the line arrived
