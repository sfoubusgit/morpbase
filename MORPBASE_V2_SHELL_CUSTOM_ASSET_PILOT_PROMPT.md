# MorpBase V2 Shell Custom Asset Pilot Prompt

## Goal

Create the first real custom-asset pilot for MorpBase V2, starting with the shell kit.

The purpose of this pilot is:

- to test whether a small authored asset layer can make the product feel more singular
- to keep the move narrow and structural
- and to avoid slipping into decorative branding or a full illustration phase

## Main Questions

### 1. What Should Be Added

- Which shell parts are the best first pilot targets?
- What kinds of marks or joins will help most?

### 2. What Must Stay Protected

- What would make the pilot too loud or too ornamental?
- What must stay code-led and restrained?

### 3. Best Pilot Shape

- What is the smallest effective first asset pilot?
- Which real surfaces should it touch?

## Output Format

Write the result as:

1. `Add`
2. `Protect`
3. `Pilot Shape`
4. `Honest Conclusion`
