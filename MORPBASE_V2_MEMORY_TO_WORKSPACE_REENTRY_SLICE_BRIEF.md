# MorpBase V2 Memory-To-Workspace Re-Entry Slice Brief

## Goal

Make return into `Workspace` feel more intentional and more distinct based on origin.

## Slice Purpose

This slice should prove that:

- returning into `Workspace` can feel like continuation
- not like loading a prefilled screen

## What This Slice Must Add

### 1. Arrival reading

Show, inside `Workspace`, a calm reading of why the user is here now.

Examples:

- continuing a kept line
- branching from a kept line
- starting from reusable shaping material
- returning inward from public work
- carrying a continuity line forward

### 2. Recommended next move

Each arrival should suggest the best next phase.

### 3. Light phase focus

The recommended phase should be lightly focused on arrival, while still allowing re-entry elsewhere.

## Suggested Re-Entry Mapping

- continue from kept work -> `Refine And Keep`
- branch from kept work -> `Shape The Look`
- use reusable asset -> `Shape The Look`
- return from public result -> `Stage The Image` or `Shape The Look` depending on action
- activate continuity -> `Define The Subject`

## Product Feel Target

After this slice, the user should feel:

- `I arrived here for a reason, and MorpBase understands that reason.`

Not:

- `This is just the same workspace with saved values loaded in.`
