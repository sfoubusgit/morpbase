# Secondary Pool Candidates For Portrait-Family Hosts

## Purpose

This document defines the first real secondary-pool candidates that fit the new secondary-pool design rules.

The goal is not to build them all immediately.
The goal is to identify the strongest candidates that can extend portrait-family main pools in a reusable way.

## Selection Rule

These candidates were chosen because they:

- fit portrait-family hosts
- add one clear dimension of variation
- do not try to become full identity anchors
- should work across multiple nearby main pools
- do not require IDPs to make sense

## Candidate 1: Hair Ornaments and Headpieces

### What it adds

A dedicated silhouette and accessory layer around the head / hair area.

### Why it is strong

This creates immediate portrait variation without replacing the main pool’s identity.
It changes readability, silhouette, decoration density, and theme flavor in a very visible way.

### Likely sections

- `Props`
- `Effects`
- maybe `Style`

### Example item types

- crystal tassel headpieces
- floral shrine clips
- moon crowns
- halo combs
- jewel braids
- chain ornaments
- winged circlets

### Host compatibility

Should work well with:

- celestial portrait hosts
- magical portrait hosts
- fantasy portrait hosts
- anime portrait hosts
- shrine / idol / witch portrait hosts

### Why it is a good first candidate

It is highly reusable inside the portrait family and visually impactful without redefining the whole workflow.

## Candidate 2: Sacred Emblems and Handheld Relics

### What it adds

A central object/emblem layer for the hands, chest, or ritual center of the portrait.

### Why it is strong

This creates narrative variation and gives the portrait a more specific focal symbol while still preserving the host identity.

### Likely sections

- `Props`
- `Effects`
- `Mood`

### Example item types

- glowing butterfly emblem
- moon relic
- crystal prayer seal
- floating sacred sigil
- radiant charm pendant
- miniature lantern core
- relic shard cluster

### Host compatibility

Should work well with:

- celestial portrait hosts
- shrine portrait hosts
- oracle portrait hosts
- magical portrait hosts
- ritual portrait hosts

### Why it is strong

It adds meaningful variation without forcing a new full character identity.

## Candidate 3: Ribbon and Jewel Accents

### What it adds

A polished decorative layer focused on ribbons, bows, brooches, charm strands, and jewel accents.

### Why it is strong

This is an especially useful differentiator for idol-like, elegant, sweet, and polished portrait workflows.
It can help separate softer idol / charm lanes from more sacred or occult lanes.

### Likely sections

- `Props`
- `Effects`
- maybe `Style`

### Example item types

- layered ribbon brooches
- jewel bow centerpieces
- charm strings
- gem tassels
- polished heart motifs
- decorative collar jewels
- stage-like sparkle ornaments

### Host compatibility

Should work well with:

- magical idol portrait hosts
- anime portrait hosts
- celestial portrait hosts
- romantic fantasy portrait hosts

### Risk

If built too broadly, it could become too sugary or too close to a whole identity lane.
So it needs discipline.

## Candidate 4: Occult Crescent Accessories

### What it adds

A darker accessory and symbolic layer centered around crescent motifs, arcane ornaments, black-lace detailing, and eerie glow accents.

### Why it is strong

This helps push darker portrait-family hosts into a distinct occult lane without replacing the host pool itself.

### Likely sections

- `Props`
- `Effects`
- `Mood`
- maybe `Lighting`

### Example item types

- crescent earrings
- arcane moon crowns
- ritual lace chokers
- dark crystal pendants
- occult charm chains
- eerie sparkle dust
- black-lilac sigil glow

### Host compatibility

Should work well with:

- celestial portrait hosts
- witch portrait hosts
- gothic anime portrait hosts
- moonlit fantasy portrait hosts

### Why it is valuable

It gives the portrait family a distinctly darker modular extension without requiring a new main pool or new Mode.

## Candidate 5: Portrait Frames and Borders

### What it adds

A decorative framing system around the portrait itself.

### Why it is useful

This can create presentation-level variation that is especially valuable in icon-like or collectible-card-like portrait workflows.

### Likely sections

- `Effects`
- `Style`
- maybe `Props`

### Example item types

- celestial border frame
- stained-glass portrait edge
- jewel lattice border
- occult glyph frame
- shrine panel framing
- ornamental star corners

### Host compatibility

Should work well with:

- celestial portrait hosts
- collectible portrait hosts
- fantasy portrait hosts
- icon-like portrait hosts

### Caution

This is visually useful, but it is less core than the first four candidates.
It may be a second-wave candidate rather than a first-wave one.

## Recommended Priority Order

### Best first-wave candidates

1. `Hair Ornaments and Headpieces`
2. `Sacred Emblems and Handheld Relics`
3. `Occult Crescent Accessories`

### Best second-wave candidate

4. `Ribbon and Jewel Accents`

### More optional / later

5. `Portrait Frames and Borders`

## Why This Order

The first three are strongest because they:

- create immediate variation
- still work across many portrait hosts
- are modular and visually legible
- do not compete too directly with the main pool identity

## Best Candidate For Celestial Pixel Portrait First

If only one should be built first, the strongest candidate is:

- `Sacred Emblems and Handheld Relics`

Why:

- it works with shrine, idol, and occult directions
- it creates clear visible variation
- it adds narrative and focal variety
- it stays comfortably secondary

## Final Summary

The first real secondary-pool candidates for portrait-family hosts should be modular pools that add one narrow but high-impact layer of variation.

The strongest initial candidates are:

- `Hair Ornaments and Headpieces`
- `Sacred Emblems and Handheld Relics`
- `Occult Crescent Accessories`

These are the best next pools to consider if MorpBase wants to explore secondary-pool composition seriously.
