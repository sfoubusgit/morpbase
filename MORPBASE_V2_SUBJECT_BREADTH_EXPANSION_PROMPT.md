# MorpBase V2 Subject-Breadth Expansion Prompt

Design the first controlled expansion of the `Define The Subject` layer in MorpBase V2.

This is not a request for a giant library.

This is a request for:

- the first real broadening of the center

while keeping the current workflow:

- clear
- curated
- and product-real

## What To Decide

1. How much broader should the subject set become in the next slice?
2. What kinds of subject options belong in the first expansion?
3. How curated vs open should the subject entry stay?
4. What should still wait for later?
5. What is the healthiest first coded subject-expansion slice?

## Main Protection

Do not turn the center into:

- a giant dropdown
- a sprawling library
- or generic prompt taxonomies

The subject layer should become:

- broader
- but still shaped

## Honest Standard

If this works, MorpBase should gain more believable center breadth without losing the calm guided rhythm that now makes the product feel right.
