Define the second prototype slice for MorpBase V2:

- `Phase B: Memory continuation`

Base the decision on:

## Core Goal

Define the prototype slice that proves:

- `Memory feels like continuation, not storage`

This slice should answer:

- what the user sees first when they arrive in `Memory`
- what the most important actions are
- how `Saved Work`, `Reusable Assets`, and `Capture Inbox` should behave in first-wave
- how the transition from `Workspace -> Memory -> Workspace` should feel

## Important Product Constraint

Do not let Memory drift into:

- archive cabinet
- generic library
- dashboard junk room
- or broad “everything I saved” product behavior

The slice must keep Memory as:

- a living second pole

## Required Output

Write the result to:

- `MORPBASE_V2_PHASE_B_MEMORY_PROTOTYPE_BRIEF.md`

The brief should include:

1. Executive conclusion
2. What Phase B must prove
3. The main user journey inside this slice
4. The minimum artifact set for the slice
5. The core Memory states that must be prototyped
6. The critical transitions that must be testable
7. What must feel live vs what can stay mocked
8. Gate 2 review criteria
9. The strongest failure signs
10. Final recommendation for the next artifact after the brief

## Additional Constraint

Keep the language plain and product-focused.
The brief should be understandable without technical knowledge.
