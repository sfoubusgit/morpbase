# MorpBase V2 Slice 3 Interaction Map

## Main Loop Behavior

1. `Continuity Home` should feel like an explanation of sameness through work, not an admin screen.
2. `Entity Focus` should make one recurring character feel real and worth reusing.
3. `Appearances` should make sameness visible through multiple kept works.
4. `Activate Into Workspace` should feel like bringing living continuity back into creation.

## What Must Feel Right

- continuity feels attached to real work
- the entity feels more meaningful than a saved label
- appearances feel like evidence, not a neat catalog
- activation feels valuable back in `Workspace`

## Failure Signs

- the slice feels like identity storage
- appearances feel like ordinary saved-work cards with a different title
- continuity feels overexplained instead of felt
- activation feels cosmetic instead of useful
