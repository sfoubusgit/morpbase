# MorpBase V2 Subject Specificity Layer Decision

## Decision

The first subject-specificity layer should live:

- inside `Phase 1`
- inside `Subject Core`
- as one light `distinctive clue` layer

## What This Means

After choosing a subject, the user can now make it more particular early through:

- a few curated clue suggestions
- one short input for their own clue

This should stay:

- light
- guided
- optional

It should not become:

- a new heavy block
- a large text area
- a taxonomy

## Why This Wins

The problem after subject-breadth expansion was no longer:

- lack of subject choice

It was:

- the chosen subject still feeling too archetypal for too long

So the strongest answer was:

- earlier particularity

not:

- more subject groups
- more subject libraries
- or more late refinement

## Structural Split Now

The subject-writing logic is now cleaner:

- `Phase 1` gives the line a recognizable subject and one distinctive clue
- `Phase 4` stays the later finishing-detail layer

So the product now distinguishes between:

- making the subject feel like this one
- and adding the last finishing note later

## Plain Conclusion

This is the right next deepening move for the center because it makes the line feel:

- chosen
- then particular

instead of:

- chosen
- and still generic until too late
