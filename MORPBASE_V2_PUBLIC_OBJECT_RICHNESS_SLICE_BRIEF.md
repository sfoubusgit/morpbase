# MorpBase V2 Public Object Richness Slice Brief

## Purpose

This slice should let the richer private object model start to matter publicly.

It should prove that `Community` can hold more than one meaningful object type without losing clarity.

## What This Slice Should Add

- the first public life of `Reusable Assets`
- a clear distinction between:
  - public workflow results
  - public reusable assets
- a simple way to switch or lens between those public object types
- a believable return path from public reusable assets back into private use

## What Makes Public Reusable Assets Different

Public reusable assets should feel like:

- reusable shaping material
- worth importing because they guide future work

They should not feel like:

- a second version of public workflow results
- prompt dumps
- file downloads

## What It Must Not Become

- not a broad two-object public platform overhaul
- not a many-tab community system
- not a marketplace
- not a feed of everything

## Success Criteria

This slice succeeds if:

- `Community` still feels calm and object-led
- public reusable assets feel meaningful and different
- the richer object model becomes more visible publicly
- the public loop still returns value inward
