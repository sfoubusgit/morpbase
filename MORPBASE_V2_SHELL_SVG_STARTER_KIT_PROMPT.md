# MorpBase V2 Shell SVG Starter Kit Prompt

## Goal

Create the first Illustrator-openable starter kit for the MorpBase V2 shell asset family.

The purpose of this step is:

- to move from handoff theory into actual starter assets
- to keep the kit small and usable
- and to make sure the shell family stays structural and restrained

## Main Questions

### 1. What Should Be Included

- Which shell assets are the best first starter-kit candidates?
- Which pieces are most useful to open and refine in Illustrator?

### 2. What Must Stay Protected

- What would make the kit too broad or too decorative?
- What should remain code-led for now?

### 3. Best Starter Shape

- What is the smallest useful SVG kit?
- Which pieces should be delivered first?

## Output Format

Write the result as:

1. `Include`
2. `Protect`
3. `Starter Shape`
4. `Honest Conclusion`
