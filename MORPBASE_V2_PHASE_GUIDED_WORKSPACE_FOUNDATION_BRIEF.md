# MorpBase V2 Phase-Guided Workspace Foundation Brief

## 1. Purpose

The purpose of this slice is:

- to deepen the coded `Workspace` so it feels more like true workflow authoring
- while keeping the speed and clarity of the current center

This is the first real center-growth slice after the stronger shell and richer product edges.

## 2. What This Slice Should Add

### 1. A real 4-phase rhythm

The coded `Workspace` should visibly organize around:

1. `Define The Subject`
2. `Shape The Look`
3. `Stage The Image`
4. `Refine And Keep`

The user should still be able to move freely, but the flow should now feel more authored.

### 2. Two new high-value workflow blocks

Add:

- `Presence And Signature`
- `Framing And Focus`

These are the best next blocks because they add meaningful depth without making the center too heavy.

### 3. Preserve Preview-side Keep

`Keep` must stay beside `Preview`.

That keeps:

- shaping on the left
- trust and commitment on the right

### 4. Preserve the fast first-use path

The next slice should still let a user get somewhere quickly.

So:

- only the active phase should feel fully open at first
- later phases should be visible but calmer
- the center should feel guided, not expanded just for its own sake

## 3. What It Must Not Become

- a return to V1 category density
- a wizard
- a bigger form
- a mini workflow manager
- a public/community feature detour

## 4. Success Criteria

This slice succeeds if the coded `Workspace` feels:

- more like a workflow
- more like MorpBase
- more precise without becoming heavier
- and better able to carry future center depth later

This slice fails if:

- the authoring column becomes crowded
- the user feels managed instead of guided
- or the center loses the current speed and clarity
