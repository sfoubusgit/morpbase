# MorpBase V2 Threshold Refinement V1 Prompt

## Goal

Create the first refined threshold asset set after the baseline freeze.

The purpose of this step is:

- to move beyond starter vectors into a more authored threshold language
- to keep the family unified and meaning-first
- and to make the crossings feel closer to a real Illustrator-ready direction

## Main Questions

### 1. What Should Be Refined

- Which threshold pieces gain the most from a first refinement pass?
- What should become more precise or more singular?

### 2. What Must Stay Protected

- What would make the thresholds feel ceremonial or emblem-heavy?
- What should remain calm and directional?

### 3. Best Refinement Shape

- What is the smallest useful refined set?
- What should be delivered alongside the refined assets?

## Output Format

Write the result as:

1. `Refine`
2. `Protect`
3. `Refinement Shape`
4. `Honest Conclusion`
