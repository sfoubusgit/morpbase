# MorpBase V2 Fresh-Eye Triage Map

Use this after the next fresh-eye reading.

## If the reaction is:

`the current baseline holds`

Then:
- freeze again
- protect the current baseline
- do not open a tuning pass by reflex

## If the reaction is:

`too generic`
or
`too app-like`

Then:
- open one `authored product-feel tuning` brief
- focus on shell, hierarchy expression, and signature-surface character

## If the reaction is:

`workspace still not strong enough`

Then:
- open one `center-strength tuning` brief
- focus on guidance, preview trust, and the felt gravity of the center

## If the reaction is:

`memory still too archive-like`

Then:
- open one `memory living-return tuning` brief
- focus on second-home feeling, not more features

## If the reaction is:

`community still too content-like`

Then:
- open one `community object-seriousness tuning` brief
- focus on public work as reusable, return-worthy value

## If the reaction is:

`continuity still too abstract`

Then:
- open one `continuity concreteness tuning` brief
- focus on recurrence payoff, not more continuity system

## Main rule

Only open **one** tuning lane from the next fresh-eye reading.

If more than one thing feels off, pick the strongest one first.
