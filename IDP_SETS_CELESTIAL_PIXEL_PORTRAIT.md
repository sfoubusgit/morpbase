# IDP Sets: Celestial Pixel Portrait

## Date

18 March 2026

## Purpose

This document defines the first concrete IDP sets for the `Celestial Pixel Portrait` workflow.

The goal is to create:

- clearly different baseline readings
- strong family coherence
- high iteration compatibility
- future compatibility with secondary Pools

These sets are not different Modes.

They are different identity baselines inside the same workflow family.

## Shared Workflow Family

All sets should preserve the same core family traits:

- luminous anime pixel portrait
- centered symmetrical bust framing
- pastel celestial glow family
- ornate decorative sprite detailing
- portrait-first composition

These are the shared anchors.

## Set Design Rule

Each set should differ mainly in:

- symbolic identity
- emotional register
- accessory family
- decorative emphasis

Each set should **not** redefine:

- the entire medium
- the entire composition logic
- the overall workflow orientation

## Set 1: Celestial Shrine

### Intent

This is the most serene, sacred, shrine-like reading of the workflow.

It should feel:

- calm
- luminous
- sacred
- elegant
- devotional

### Main IDP

`luminous anime pixel portrait, centered symmetrical bust framing, pastel celestial glow, ornate decorative sprite detailing`

### Support 1

`large glowing eyes with delicate floral and shrine-like ornaments`

### Support 2

`soft crystalline highlights with celestial sparkles and sacred glow accents`

### Visual center

- sacred symmetry
- floral ornaments
- divine light
- shrine-maiden softness

### Best secondary pool compatibility

Strong with:

- floral ornament pools
- sacred symbol pools
- moon / star symbol pools
- soft emotional tone pools
- ceremonial accessory pools

## Set 2: Magical Idol

### Intent

This is the more radiant, performative, magical-girl / idol-adjacent reading of the workflow.

It should feel:

- bright
- polished
- charming
- glamorous
- emotionally vivid
- stage-like

### Main IDP

`luminous anime pixel portrait, centered symmetrical bust framing, pastel celestial glow, ornate decorative sprite detailing`

### Support 1

`large sparkling eyes with elegant ribbons, jewel ornaments, and magical idol accessories`

### Support 2

`soft crystalline highlights with radiant glitter accents, polished charm motifs, and candy-color glow`

### Visual center

- ribbons
- jewel accents
- charm motifs
- polished magical accessories
- brighter sparkle language
- sweeter stage-ready luminous presence

### Best secondary pool compatibility

Strong with:

- ribbon pools
- magical accessory pools
- jewel ornament pools
- heart / charm symbol pools
- cheerful emotional tone pools
- performance / elegance accent pools
- polished costume accent pools

## Set 3: Occult Pastel

### Intent

This is the darker, stranger, dream-occult reading of the same family.

It should feel:

- mysterious
- hypnotic
- soft-dark
- arcane
- quietly uncanny

### Main IDP

`luminous anime pixel portrait, centered symmetrical bust framing, pastel celestial glow, ornate decorative sprite detailing`

### Support 1

`large glowing eyes with occult ornaments and delicate crescent accessories`

### Support 2

`soft crystalline highlights with eerie pastel sparkles and arcane glow accents`

### Visual center

- crescent motifs
- stranger ornamentation
- occult softness
- dreamlike uncanny glow

### Best secondary pool compatibility

Strong with:

- occult symbol pools
- crescent / astral icon pools
- eerie emotional tone pools
- arcane accessory pools
- night-glow accent pools

## Why The Main IDP Stays Shared

All three sets use the same main IDP on purpose.

Reason:

- the family identity should remain stable
- the variation should come from the supporting baseline phrases
- this keeps the workflow coherent while still producing distinct readings

This is good for iteration and future compatibility.

## Where The Sets Actually Differ

### Celestial Shrine

- sacred
- floral
- devotional

### Magical Idol

- radiant
- glamorous
- charming

### Occult Pastel

- arcane
- uncanny
- dreamy-dark

That is enough difference to matter without fragmenting the workflow family.

## Recommendation For First Real Use

If this becomes the first real Multi IDP Set workflow, I recommend:

### Default first active set

- `Celestial Shrine`

Why:

- it is broad
- elegant
- highly compatible
- least likely to over-narrow the workflow too early

### Then compare

- `Magical Idol`
- `Occult Pastel`

This will let us observe whether selectable identity baselines create meaningful workflow variation.

## Current Verdict

These three sets are strong enough to act as the first concrete example of the Multi IDP Set System.

They are:

- distinct
- coherent
- modular
- still compatible with future secondary Pools
