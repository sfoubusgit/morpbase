# MorpBase V2 Trace SVG Starter Kit Prompt

## Goal

Create the first Illustrator-openable starter kit for the MorpBase V2 trace family.

The purpose of this step is:

- to move the trace family from CSS proof into actual starter vectors
- to keep the family quieter than thresholds
- and to preserve its residue-like, readable feeling

## Main Questions

### 1. What Should Be Included

- Which trace assets are the best first starter-kit candidates?
- Which pieces are most useful to open and refine in Illustrator?

### 2. What Must Stay Protected

- What would make the kit too loud, too connected, or too ornamental?
- What should remain code-led for now?

### 3. Best Starter Shape

- What is the smallest useful SVG kit?
- Which trace pieces should be delivered first?

## Output Format

Write the result as:

1. `Include`
2. `Protect`
3. `Starter Shape`
4. `Honest Conclusion`
