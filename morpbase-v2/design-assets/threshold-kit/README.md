# MorpBase V2 Threshold SVG Starter Kit

This folder contains the first Illustrator-openable starter assets for the MorpBase V2 threshold family.

These are not final assets.

They are:

- starter vectors
- sized to be easy to open and refine
- tied directly to the current coded threshold language

## Files

- `shared-threshold-family.svg`
- `keep-threshold.svg`
- `publish-threshold.svg`
- `use-threshold.svg`
- `activate-threshold.svg`

## Meaning

### Shared threshold family

- purpose: show the base crossing grammar
- shared ideas:
  - threshold brackets
  - directional path
  - crossing node
  - restrained asymmetry

### Keep

- meaning: inward crossing into a second home
- current hooks:
  - `.keep-threshold-band`
  - `.keep-action`

### Publish

- meaning: outward crossing into public life
- current hooks:
  - `.publishing-threshold-band`
  - `.publish-action`

### Use

- meaning: return crossing into live creation
- current hooks:
  - `.asset-threshold-band`
  - `.use-action`

### Activate

- meaning: recurrence crossing into live creation
- current hooks:
  - `.continuity-threshold-band`
  - `.activate-action`

## Use Rule

These assets should be refined in Illustrator with the same restraint already proven in code:

- meaningful, not dramatic
- directional, not emblematic
- small family, not symbol inflation

## Suggested Order

1. refine the shared family grammar
2. refine `Keep`
3. refine `Publish`
4. refine `Use`
5. refine `Activate`
