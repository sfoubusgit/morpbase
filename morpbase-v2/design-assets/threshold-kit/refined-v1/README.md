# MorpBase V2 Threshold Refinement V1

This folder contains the first refined threshold asset set after the starter-kit baseline.

These are still not final assets.

They are:

- a more authored refinement pass
- still restrained
- still tied to the coded threshold language

## Files

- `overview-board.svg`
- `shared-threshold-family-refined.svg`
- `keep-threshold-refined.svg`
- `publish-threshold-refined.svg`
- `use-threshold-refined.svg`
- `activate-threshold-refined.svg`

## Refinement Aim

Compared to the starter kit, this pass should feel:

- more precise
- more unified
- more believable as real MorpBase crossing language

without feeling:

- heavier
- emblem-like
- or detached from the product
