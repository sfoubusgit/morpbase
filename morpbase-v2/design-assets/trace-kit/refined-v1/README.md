# MorpBase V2 Trace Refinement V1

This folder contains the first refined trace asset set after the starter-kit baseline.

These are still not final assets.

They are:

- a more authored refinement pass
- still restrained
- still tied to the coded trace language

## Files

- `overview-board.svg`
- `shared-trace-family-refined.svg`
- `center-arrival-trace-refined.svg`
- `memory-trace-refined.svg`
- `public-trace-refined.svg`
- `continuity-trace-refined.svg`

## Refinement Aim

Compared to the starter kit, this pass should feel:

- more precise
- more singular
- more believable as real MorpBase trace language

without feeling:

- heavier
- graph-like
- or detached from the product

## Suggested Use Order

1. inspect `overview-board.svg`
2. refine the shared family grammar
3. refine center arrival trace
4. refine memory trace
5. refine public trace
6. refine continuity trace
