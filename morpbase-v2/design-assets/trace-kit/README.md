# MorpBase V2 Trace SVG Starter Kit

This folder contains the first Illustrator-openable starter assets for the MorpBase V2 trace family.

These are not final assets.

They are:

- starter vectors
- sized to be easy to open and refine
- tied directly to the current coded trace language

## Files

- `shared-trace-family.svg`
- `center-arrival-trace.svg`
- `memory-trace.svg`
- `public-trace.svg`
- `continuity-trace.svg`

## Meaning

### Shared trace family

- purpose: show the base residue grammar
- shared ideas:
  - fine carried line
  - node weight
  - quiet segmentation
  - restrained asymmetry

### Center arrival trace

- meaning: carried value arrived back at the center
- current hooks:
  - `.arrival-trace-band`
  - `.preview-arrival-trace`

### Memory trace

- meaning: enduring carried value
- current hooks:
  - `.memory-carried-trace-band`
  - `.trace-language-memory`

### Public trace

- meaning: outward travel and readable public consequence
- current hooks:
  - `.public-carried-trace-band`
  - `.response-lineage-trace-band`
  - `.trace-language-community`

### Continuity trace

- meaning: readable sameness across appearances
- current hooks:
  - `.continuity-carried-trace-band`
  - `.trace-language-continuity`

## Use Rule

These assets should be refined in Illustrator with the same restraint already proven in code:

- readable, not decorative
- fine, not loud
- residue, not icon

## Suggested Order

1. refine the shared family grammar
2. refine center arrival trace
3. refine memory trace
4. refine public trace
5. refine continuity trace
