# MorpBase V2 Design Assets Baseline

This folder now contains two layers of MorpBase V2 custom assets:

1. starter-kit baseline
2. refined V1 baseline

The live product now also has:

- an integrated design baseline built from those refined families

The current active working layer is:

- `refined-v1` inside each family

The starter kits remain:

- the origin baseline
- the fallback layer
- the clean simplest handoff state

## Families

This folder contains three asset families:

1. `shell-kit`
2. `threshold-kit`
3. `trace-kit`

These are not final assets.

Across those families, the assets are:

- Illustrator-openable starter vectors
- refined V1 vector sets
- tied to current coded hooks
- restrained by the same product rules already proven in the app

## Current Family Order

### 1. Shell kit

- whole-product frame
- brand support
- shell-to-engine joins

### 2. Threshold kit

- `Keep`
- `Publish`
- `Use`
- `Activate`

### 3. Trace kit

- center arrival
- memory endurance
- public consequence
- continuity recurrence

## Use Rule

Work from this folder in the same order:

1. shell
2. thresholds
3. traces

Do not widen into:

- new asset families
- realm art systems
- general decoration

until there is a deliberate decision to do that.
