# MorpBase V2 Shell Refinement V1

This folder contains the first refined shell asset set after the starter-kit baseline.

- a more authored refinement pass
- still restrained
- still tied to the coded shell language

## Refinement Aim

Compared to the starter kit, this pass should feel:

- more precise
- more singular
- more believable as real MorpBase shell language

without feeling:

- heavier
- ornamental
- or detached from the product
