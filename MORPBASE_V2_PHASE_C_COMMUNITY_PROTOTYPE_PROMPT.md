# MorpBase V2 Phase C Community Prototype Prompt

## Purpose

Define the prototype brief for `Phase C: Community circulation`.

This slice must not prototype Community as:

- a browse-only destination
- a social feed
- a marketplace
- or a detached publishing zone

It must prototype Community as:

- the public circulation layer of real MorpBase objects

## Core Question

What is the smallest prototype slice that can prove:

- Community feels public and alive
- public objects feel worth opening
- creator presence feels real
- publishing feels downstream from actual work
- import feels like adoption into personal practice

without making MorpBase feel:

- image-first
- feed-first
- or socially generic

## What Phase C Must Prove

The brief must define a slice that proves:

1. `Discover` feels like public circulation of real MorpBase work
2. visible outcomes make public objects feel worth opening
3. `Public Workflow Results` and `Public Reusable Assets` feel clearly different
4. creator pages feel object-grounded, not like generic profiles
5. publishing begins from real private work
6. import into `Memory` feels meaningful and practical
7. the public loop clearly returns to private use

## Slice Discipline

Do not let this slice become:

- the whole Community realm
- a full publishing dashboard
- a full social system
- a challenge/reward prototype

But do allow the brief to preserve light headroom for:

- sharing
- real recognition
- future collaboration
- later challenge/storyline vitality
