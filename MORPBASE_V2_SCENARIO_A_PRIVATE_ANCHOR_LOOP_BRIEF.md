# MorpBase V2 Scenario A Private Anchor Loop Brief

## Scenario

`Private Anchor Loop`

## Path

1. enter `Workspace` fresh
2. shape one believable line
3. cross through `Keep`
4. land in `Memory`
5. choose `Continue this line`
6. return into `Workspace`

## What to judge

- does the first-use center still feel guided and alive
- does `Prompt Preview` still build trust at the right time
- does `Keep` still feel like a crossing
- does `Memory` still feel like living return
- does re-entry feel like continuation instead of reset

## Plain questions

- does this feel like one creative loop
- where does it still feel too app-like
- where does it already feel convincingly MorpBase
- is there any step that still feels more technical than meaningful

## Failure signs

- too many choices too early
- `Keep` feels administrative
- `Memory` feels neatly organized but dead
- return to `Workspace` feels like loading an old draft

## Success reading

If this scenario passes cleanly, the current V2 baseline is probably strong at its core.
