# MorpBase V2 Phase Set Analysis

## 1. Executive Conclusion

The strongest phase set for the MorpBase V2 benchmark workflow is a **balanced 4-phase model**:

1. `Define The Subject`
2. `Shape The Look`
3. `Stage The Image`
4. `Refine And Keep`

This is the best phase set because it:

- feels like real creative movement
- supports the portrait benchmark clearly
- avoids both wizard rigidity and vague openness
- stays different from the old V1 category model
- leaves room for later reusable context and continuity layers

The most important judgment is:

- V2 should not use too few phases and become generic
- and it should not use too many phases and become over-segmented

The balanced 4-phase set gives MorpBase the clearest authoring rhythm for a true V2 beginning.

## 2. Candidate Phase Sets

### 1. Compressed 3-phase model

Example shape:

- Define
- Shape
- Keep

Strengths:

- simple
- fast
- low explanation cost

Weaknesses:

- too broad
- phases become vague
- not enough structure for the portrait benchmark
- risks feeling generic

### 2. Balanced 4-phase model

Example shape:

- Define The Subject
- Shape The Look
- Stage The Image
- Refine And Keep

Strengths:

- enough movement to feel like a workflow
- still compact enough for first use
- each phase has a distinct creative job
- strong fit for portrait creation

Weaknesses:

- requires discipline so “look” and “stage” stay meaningfully separate

### 3. Detailed 5-phase model

Example shape:

- Set Intent
- Define Subject
- Shape Look
- Stage Image
- Refine And Keep

Strengths:

- more explicit
- more room for nuance

Weaknesses:

- too segmented for first-wave
- “Set Intent” often becomes a thin pre-phase
- more risk of wizard feel

### 4. Old-category regrouped model

Example shape:

- subject cluster
- style cluster
- environment cluster
- camera/effects cluster

Strengths:

- easy to derive from V1

Weaknesses:

- too close to the old Builder
- taxonomy-first instead of workflow-first
- does not feel like a truly new V2 beginning

## 3. Selection Criteria

The phase set should win on:

### 1. Creative movement

Do the phases feel like real steps in making a better image prompt?

### 2. Benchmark fit

Do they support the portrait workflow naturally?

### 3. First-use clarity

Can a user understand what each phase is for quickly?

### 4. Repeat-use efficiency

Can a returning user jump back into one phase without replaying the whole flow?

### 5. V2-newness

Does the set feel like a genuinely new workflow model rather than V1 categories grouped differently?

### 6. Future headroom

Can later reusable context, continuity, and archive depth plug into the phases without redefining them?

## 4. Real-Life Usage Drafts

### Draft 1. First-time portrait creator

Goal:

- build one strong portrait prompt quickly

Using the 3-phase model:

- easy to enter
- but “Shape” becomes too broad
- user can lose clarity about what kind of decision they are making

Using the 5-phase model:

- feels thorough
- but “Set Intent” adds a light pre-step that slows first value

Using the 4-phase model:

- user understands the sequence naturally:
  - who is this
  - what should it look/feel like
  - where/how is it staged
  - now tighten and keep it

Why 4-phase feels strongest:

- the phases match actual creative movement without feeling bureaucratic

### Draft 2. Returning user refining a saved portrait base

Goal:

- reopen a saved base and quickly change style, lighting, and framing

Using the 3-phase model:

- too much is hidden inside “Shape”
- refinement targets are not distinct enough

Using the 5-phase model:

- usable
- but the extra phase adds little value in targeted return use

Using the 4-phase model:

- the user can jump directly to:
  - `Shape The Look`
  - `Stage The Image`

Why 4-phase feels strongest:

- phases are distinct enough for targeted re-entry
- but not so many that movement becomes fussy

### Draft 3. Later user with deeper reusable context

Goal:

- later apply reusable context or continuity without breaking the benchmark flow

Using the 3-phase model:

- hard to know where later systems should connect

Using the 5-phase model:

- there is space, but it risks over-specializing the core too early

Using the 4-phase model:

- later systems can attach clearly:
  - subject-related continuity into `Define The Subject`
  - style/workflow context into `Shape The Look`
  - environment/context support into `Stage The Image`

Why 4-phase feels strongest:

- it creates natural future attachment points without needing those systems now

## 5. Chosen Phase Set

The chosen phase set is:

1. `Define The Subject`
2. `Shape The Look`
3. `Stage The Image`
4. `Refine And Keep`

This should be treated as a functional phase set, not necessarily the final visible copy.

The important part is the phase logic:

- subject definition first
- visual/aesthetic shaping second
- scene/composition staging third
- refinement/save fourth

That is a stronger workflow rhythm than the current V1 category map.

## 6. What Each Phase Owns

### 1. Define The Subject

Owns:

- who or what the image is fundamentally about
- the core portrait subject direction
- the baseline identity of the prompt result

Does not own:

- final style logic
- staging/composition logic
- archive or save behavior

### 2. Shape The Look

Owns:

- visual direction
- mood and lighting
- surface style pressure
- aesthetic tone

Does not own:

- core subject definition
- scene placement
- final archive actions

### 3. Stage The Image

Owns:

- environment/background pressure
- framing/composition
- image presentation emphasis
- how the subject is situated and seen

Does not own:

- deep subject definition
- the full aesthetic language by itself
- save/reuse logic

### 4. Refine And Keep

Owns:

- final tightening
- last useful adjustments
- confirmation via Preview
- the save / keep handoff

Does not own:

- the whole workflow by itself
- deep archive structure
- later community or continuity systems

## 7. What Workflow Blocks Belong In Each Phase

### Define The Subject

Likely block types:

- subject core
- role / archetype
- key presence or defining trait

### Shape The Look

Likely block types:

- visual style direction
- mood
- light
- texture or finish pressure

### Stage The Image

Likely block types:

- setting / background pressure
- framing
- composition emphasis
- camera/presentation angle if needed

### Refine And Keep

Likely block types:

- final polish
- constraint cleanup
- confidence/review cues
- save as reusable base

These are workflow blocks, not final UI labels.
The important principle is that each block should feel like a meaningful creative move.

## 8. How The User Moves Between Phases

Movement should be:

- **strongly suggested, but not hard-gated**

That means:

- the workspace should always suggest the next best phase
- but the user should be free to revisit earlier phases at any time

The benchmark flow should feel like:

1. start in `Define The Subject`
2. move naturally into `Shape The Look`
3. then into `Stage The Image`
4. then into `Refine And Keep`

But a returning user should be able to:

- jump straight back into `Shape The Look`
- or `Stage The Image`

without replaying the whole workflow.

## 9. How The Phase Set Supports Later Depth

This phase set supports later depth because it creates clean future attachment points.

### 1. Reusable source/context systems

Can later support:

- look-shaping help inside `Shape The Look`
- staging help inside `Stage The Image`

### 2. Continuity systems

Can later support:

- subject continuity injection inside `Define The Subject`
- maybe look-continuity support where appropriate

### 3. Archive/reuse depth

Can later deepen `Refine And Keep` without changing the earlier phases.

### 4. Community/publication

Can later attach after `Refine And Keep`, not inside the core phase flow.

So the 4-phase set keeps the benchmark flow clean while still preparing for later product layers.

## 10. Why The Other Phase Sets Lose

### 3-phase model loses

Because it is too compressed and risks making MorpBase feel generic.

### 5-phase model loses

Because it is too segmented for first-wave and starts to feel more staged than necessary.

### Old-category regrouped model loses

Because it is too close to V1 and too taxonomy-driven.

The 4-phase model wins because it is the best balance of:

- clarity
- rhythm
- creative meaning
- flexibility
- and future headroom

## 11. Phase Set Failure Conditions

The phase set would fail if:

### 1. The phases become generic shells

Then they would not guide real workflow movement.

### 2. `Shape The Look` and `Stage The Image` collapse into one vague middle

Then the flow would lose clarity.

### 3. `Refine And Keep` becomes an archive management phase

Then save/reuse would overpower the live workflow.

### 4. The phases are treated as hidden taxonomy buckets

Then V2 would drift back toward V1 thinking.

### 5. Later systems force more and more phases into the core

Then the phase set is not stable enough.

## 12. Final Judgment

The strongest V2 phase set for the benchmark workflow is:

1. `Define The Subject`
2. `Shape The Look`
3. `Stage The Image`
4. `Refine And Keep`

This is the best choice because it gives MorpBase:

- a real workflow rhythm
- strong first-use clarity
- easy revisitability
- a natural save moment
- and clean future attachment points

The cleanest final sentence is:

- `MorpBase V2 should structure its benchmark authoring flow around four creative movements: define the subject, shape the look, stage the image, and refine and keep the result.`

That is the strongest current phase set for a truly new V2 workspace.
