# MorpBase V2 Slice 4 Coherence Tightening Prompt

## Goal

Define the next coded V2 slice as a **whole-product coherence tightening pass**.

This slice is not for adding a new system.

Its job is to make the current coded V2 feel more like:

- one integrated MorpBase engine

and less like:

- several correct but still slightly separate realm slices

## Starting Point

The current coded V2 already has:

- `Workspace`
- `Memory`
- `Community`
- `Continuity`

And the whole-product coded synthesis review has already judged:

- the direction is right
- the loops are real
- but the current product still feels slightly too prototype-like and slightly too discrete across realms

## Main Questions

### 1. Integration

- How should the current V2 make cross-realm value flow more visible?
- How should transitions feel less like screen jumps and more like continuation?
- How should `Memory` read even more clearly as the bridge layer?

### 2. Product Feel

- What should be strengthened so the total V2 feels more product-real?
- What kind of coherence improvements are worth doing before any new expansion?
- What should be improved without pretending we are already doing the final design universe?

### 3. Scope Discipline

- What belongs in this coherence slice?
- What should stay out because it would be premature expansion?

## Required Output

Write the result as:

1. `Purpose`
2. `What This Slice Should Improve`
3. `What This Slice Must Not Become`
4. `Recommended Focus Areas`
5. `Success Criteria`
6. `What Comes After This Slice`

## Guardrails

- do not add a new realm
- do not broaden reward, collaboration, challenges, or storylines yet
- do not treat this as the final visual identity pass
- do not reopen the frozen product foundation
- do not drift into vague polish language; keep the improvements concrete
