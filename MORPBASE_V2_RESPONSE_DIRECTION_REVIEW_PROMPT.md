# MorpBase V2 Response Direction Review Prompt

## Goal

Review the first coded `response direction` slice in V2.

The purpose of this review is:

- to judge whether public workflow results now express a clearer invited response
- to confirm that the new layer still feels calm and creator-set
- to catch any drift toward challenge prompts, tasking, or contest framing

## Review Questions

### 1. Product Meaning

- Does response direction make public work easier to answer?
- Does it make the invitation feel clearer without making it heavier?

### 2. Tone

- Does the slice stay gentle and product-real?
- Or does it start to sound like a brief, task, or challenge?

### 3. Object Fit

- Does the direction layer strengthen public workflow results?
- Does it stay clearly secondary to real creation?

### 4. Discipline

- Does this avoid challenge language and creator-task language?
- Does it stay far enough away from event or contest behavior?

## Output Format

Write the result as:

1. `Verdict`
2. `What Now Works`
3. `Remaining Caution`
4. `Best Next Move`
