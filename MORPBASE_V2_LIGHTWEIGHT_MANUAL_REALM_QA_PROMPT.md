# MorpBase V2 Lightweight Manual Realm QA Prompt

Goal:
- run the smallest useful manual product-feel QA pass across the support realms

Target realms:
- `Memory`
- `Community`
- `Continuity`

What to judge:
- does `Memory` still feel like a second home instead of storage
- does `Community` still feel like the public life of real work instead of a content app
- does `Continuity` still feel light, readable, and real instead of abstract
- do all three still clearly support the stronger `Workspace` center

Method:
- use a short manual checklist
- prefer product-feel judgments over technical observations
- keep the pass small enough to repeat later

Guardrails:
- do not turn this into a big QA matrix
- do not chase edge cases in this step
- only recommend code tightening if a realm feels clearly off

Success condition:
- the support-realm reading is clear
- the next move is either a selective tuning brief or a freeze
