# MorpBase V2 Threshold SVG Starter Kit Prompt

## Goal

Create the first Illustrator-openable starter kit for the MorpBase V2 threshold family.

The purpose of this step is:

- to move the threshold family from CSS proof into actual starter vectors
- to keep the family clearly unified
- and to preserve its calm, meaning-first reading

## Main Questions

### 1. What Should Be Included

- Which threshold assets are the best first starter-kit candidates?
- Which pieces are most useful to open and refine in Illustrator?

### 2. What Must Stay Protected

- What would make the kit too dramatic or emblem-like?
- What should remain code-led for now?

### 3. Best Starter Shape

- What is the smallest useful SVG kit?
- Which threshold pieces should be delivered first?

## Output Format

Write the result as:

1. `Include`
2. `Protect`
3. `Starter Shape`
4. `Honest Conclusion`
