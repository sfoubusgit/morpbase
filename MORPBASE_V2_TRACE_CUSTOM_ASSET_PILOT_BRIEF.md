# MorpBase V2 Trace Custom Asset Pilot Brief

## Intent

This pilot should prove that the trace family can become more truly authored without losing:

- calmness
- consequence-reading
- and its quieter place beneath the threshold family

## Scope

Touch only:

- carried-trace bands
- public-trace bands
- recurrence-trace bands
- center arrival-trace bands

Do not turn this into:

- a threshold pass
- a shell pass
- a broad card-surface redesign
- or a visible motif spread across ordinary panels

## Desired Feeling

The result should feel:

- finer
- more held
- more MorpBase-native

but not:

- louder
- more connected for its own sake
- or more graph-like

## Honest Standard

If this pilot works, the trace family should feel more like:

- one quiet authored residue language

and less like:

- several good coded trace bands
