# Elasticity Test: Gothic Character Portrait

## Date

19 March 2026

## Purpose

This elasticity test checks whether the current MorpBase system can already support a strong `Gothic Character Portrait` workflow through:

- the current Builder Workflow Modes
- the official `Gothic Character Portrait` pool
- IDP set switching
- Territories
- current Builder guidance

without requiring a new Mode or a deeper structural change.

## Candidate Workflow

Test target:

- `Gothic Character Portrait`

This is intentionally portrait-centered.

It is not:

- all gothic art
- all dark fantasy scenes
- all horror imagery
- all industrial goth fashion photography

It is specifically:

- upper-body gothic character portrait iteration
- with strong mood, attire, lighting, and symbolic motif continuity

## Why This Is A Good Elasticity Test

This workflow is useful because it pressures the system in a different way from the earlier `32x32 Pixel Art Portrait` test.

It tests:

- darker emotional tone
- more shadow-dependent visual logic
- more fashion / attire dependence
- stronger symbolic motif layering
- whether internal pool sub-lanes stay distinct without breaking family coherence

Can the current MorpBase system support repeated gothic portrait iteration in a way that is:

- distinct across lanes
- intuitive to build with
- and not dependent on a new Builder Mode?

## Test Procedure

### Phase 1: Baseline without Territory

Test the pool with:

- `Character-First`
- `Balanced`

Questions:

- does the workflow already feel natural?
- do the initiative phrases help establish the gothic family?
- do the sections support intuitive gathering well?

### Phase 2: IDP lane testing

Switch explicitly between:

- `Mourning Lace`
- `Crimson Noble`
- `Ashen Industrial`

Questions:

- do these sets feel meaningfully different?
- do they still remain part of the same larger workflow family?
- does one lane dominate too strongly over the others?

### Phase 3: Territory-enabled

Activate the Territory and test:

- `Territory-biased`
- `Full Builder`

Questions:

- does Territory improve gothic focus?
- does it help intuitive gathering or over-constrain it?
- does it make the workflow feel more coherent or more rigid?

### Phase 4: Compare workflow feel

Compare:

- `Character-First`
- `Balanced`
- optional `Scene-First`

Questions:

- which one feels most natural?
- does any mode seem structurally wrong for the workflow?
- does the system feel blocked by orientation or by pool/territory tuning instead?

## What To Observe

Track observations under these categories.

### 1. Mode Fit

Questions:

- does `Character-First` support the workflow cleanly?
- does `Balanced` feel equally good or more flexible?
- does `Scene-First` add anything useful?
- is a missing orientation really the issue, or not?

### 2. Pool Quality

Questions:

- are the sections strong enough?
- are `Attire`, `Mood`, and `Motifs` doing real work?
- do the initiative phrases establish a useful gothic baseline?
- does the pool feel like a coherent primary host?

### 3. IDP Quality

Questions:

- do the 3 IDP sets feel distinct enough?
- are any two too similar?
- do the sets produce lane variation without fragmenting the workflow?

### 4. Territory Quality

Questions:

- does the Territory improve the workflow meaningfully?
- does Territory-biased navigation still feel useful here?
- do the chosen sections create the right focused subset?

### 5. Guided Intuitive Selection Fit

Questions:

- does the workflow support intuitive selection well?
- can the user “grab what feels right” without losing identity?
- does the gothic family still hold under instinctive prompt gathering?

### 6. Drift Risk

Questions:

- does the workflow remain recognizably gothic across variations?
- does it drift into generic dark fantasy or generic fashion portrait too easily?
- do the lane changes preserve family identity?

## Interpretation Rules

This is important.

Do not conclude `new mode needed` just because a dark workflow feels complex.

Use these distinctions:

### If it works well

Conclusion:

- no new Mode needed

### If it works, but lane separation is weak

Conclusion:

- sharpen pool items or IDP sets first

### If it works, but Territory feels awkward

Conclusion:

- refine Territory composition or wording first

### If it fails structurally even under strong setup

Conclusion:

- a deeper workflow gap may exist
- only then discuss whether a new Mode or deeper system change is justified

## Most Likely Current Hypothesis

My current expectation is:

- the system will probably support this workflow
- but the more likely pressure point will be:
  - how distinct the IDP sets feel in practice

not:

- a truly missing Builder Mode

## Provisional Success Standard

This test should count as a success for the current system if:

- `Character-First` or `Balanced` supports multiple strong gothic portrait variations
- the gothic family persists across those variations
- the 3 IDP sets feel meaningfully different but still related
- Territory improves focus without causing major rigidity
- no repeated structural failure points toward a missing orientation
