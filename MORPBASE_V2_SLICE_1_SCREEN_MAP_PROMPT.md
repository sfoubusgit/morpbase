# MorpBase V2 Slice 1 Screen Map Prompt

Use this prompt after the Slice 1 build brief has been accepted.

Your job is to translate Slice 1 into an exact screen-and-state map for the new V2 project.

## Core Goal

Define the smallest complete screen map for the first V2 build slice so that:

- the `Workspace + Memory` core loop is concrete
- the slice still feels like real MorpBase
- and the build can stay focused without growing into a multi-realm product too early

## Required Inputs

Read these first:

- `MORPBASE_V2_SLICE_1_BUILD_BRIEF.md`
- `MORPBASE_V2_PRODUCT_BLUEPRINT.md`
- `MORPBASE_V2_INTERACTION_BLUEPRINT.md`

- `MORPBASE_V2_PHASE_A_WORKSPACE_PROTOTYPE_BRIEF.md`
- `MORPBASE_V2_PHASE_B_MEMORY_PROTOTYPE_BRIEF.md`

## Main Questions

Answer these directly:

1. What exact screens or states belong inside Slice 1?
2. Which of those are full screens versus transitional states?
3. What are the critical transitions between them?
4. What should be visible in the shell during Slice 1?
5. What is still intentionally absent from this slice?

## Required Output

Write one concise screen map document that includes:

- executive conclusion
- the screen/state list
- which parts are full screens
- which parts are transition states
- primary transitions
- what stays visible in the shell
- what stays out of scope
- final next-step recommendation

Save the result as:

- `MORPBASE_V2_SLICE_1_SCREEN_MAP.md`

## Important Rules

- Keep the slice centered on `Workspace + Memory`.
- Do not silently smuggle in `Community` or `Continuity`.
- Preserve the asymmetric shell.
- Make the screen map practical enough to guide the next planning artifact.
