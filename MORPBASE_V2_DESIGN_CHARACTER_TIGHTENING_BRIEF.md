# MorpBase V2 Design-Character Tightening Brief

## 1. Purpose

The purpose of this phase is:

- to make the current coded V2 feel more like one authored MorpBase product
- and less like a strong multi-slice prototype

The structure is now strong enough.
The next gain should come from stronger expression.

## 2. What This Phase Should Strengthen

### 1. Shell identity

The shell should feel more characteristic, more confident, and more like a real product world.

### 2. Hierarchy through visual force

`Workspace`, `Memory`, `Community`, and `Continuity` should not only be structurally different.
They should feel different in the right hierarchy through visual weight, tone, and emphasis.

### 3. Cross-realm carried-work feeling

The product should feel more clearly like the same meaningful work is moving through different forms of value.

### 4. Product atmosphere

The coded V2 should feel more crafted, more human, and more distinct from a generic app shell.

## 3. Strongest Coded Targets

### 1. Top shell and engine strip

These should more clearly express:

- center
- return logic
- realm hierarchy

### 2. Cross-realm bridge surfaces

Return paths, carried-work summaries, and object handoffs should feel more visually intentional.

### 3. Object focus surfaces

The major focus areas in `Memory`, `Community`, and `Continuity` should feel more like members of one product family.

### 4. Preview and proof surfaces

`Prompt Preview`, result focus surfaces, and proof-oriented zones should feel more trustworthy and signature-rich.

### 5. Early shape-language consistency

Recurring shape language, panel behavior, and atmospheric cues should become stronger so later custom Illustrator work has a better coded base to attach to.

## 4. What Must Stay Out

- no new systems
- no new participation mechanics
- no fake polish detached from product meaning
- no flattening into a cleaner but more generic app
- no pretending this is the final full art/design universe already

## 5. Success Criteria

This phase succeeds if the coded V2 feels:

- more distinct
- more integrated
- more product-real
- more unmistakably like MorpBase

without needing new structural expansion first
