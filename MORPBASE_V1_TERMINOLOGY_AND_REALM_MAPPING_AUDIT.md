# MorpBase V1 Terminology And Realm Mapping Audit

## Core judgment
V1 already contains most of the future MorpBase parts.

The main missing piece is not structure.
It is clearer top-level meaning.

## Best mapping

### Workspace
Maps to:
- Builder
- Prompt Preview as its live companion

### Memory
Maps to:
- Saved Prompts
- Prompt Archive
- Prompt Library save/reopen/reuse flow

### Community
Maps to:
- Pool Hub
- public creator pages
- public pools / public prompts

### Continuity
Maps to:
- Identity Systems
- Character Identity
- later recurring identity lanes

### Profile
Maps to:
- My Profile
- public creator identity

## Best first pass
Only do a light rename/reframe pass:
- `Builder` -> `Workspace`
- `Saved Prompts` / `Prompt Archive` -> `Memory`
- `Identity Systems` -> `Continuity`
- `Community Pools` / `Pool Hub` -> `Community`
- `My Profile` -> `Profile`

Do not redesign V1 to look like current V2.
Do not rewrite the real architecture yet.

## Goal
Test whether V1 feels better, not worse, when the stronger V2 conception is layered onto it.
